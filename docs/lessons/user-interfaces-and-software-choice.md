# User interfaces

Lesson: [student page](../../pages/topics/user-interfaces-and-software-choice.html). Unit 2 A2: GUI, CLI, menu-based interfaces and suitability.
Authoring: the linked HTML and its page script.
Depth: [definitions](../lesson_authoring.md#coverage-outline-format). Section IDs below refer to the lesson page.

## Coverage in order

1. **Introduced** — Interface purpose and the three styles. (`overview`)
2. **Covered** — GUI elements, discoverability, strengths and limitations. (`gui`)
3. **Developed** — CLI interaction: prompt, command and output. (`command-line`)
4. **Introduced** — Fixed PowerShell examples for location, folders, processes, help and pipelines; illustrate interaction, not syntax proficiency. (`current-location`)
5. **Covered** — CLI benefits, repetition/automation and uses in development, cybersecurity, data work and servers. (`why-cli`)
6. **Covered** — CLI limitations and appropriate users/tasks. (`cli-tradeoffs`)
7. **Covered** — Menu-based interaction, constrained choices, real examples and trade-offs. (`menu-based`)
8. **Covered** — Mixed interfaces and comparison of the three styles. (`combined-styles`)
9. **Covered** — Factors affecting interface choice and use. (`interface-suitability`)
10. **Practice** — Worked suitability scenarios, paired choice/reason activity, misconceptions, quiz and written tasks. (`worked-scenarios`)
