# Hardware performance and component choice

Lesson: [student page](../../pages/topics/hardware-performance-and-component-choice.html). Unit 2 A1: hardware performance and selection.
Prerequisites: Basic system/component and input/output/storage roles.
Authoring: the linked HTML and its page script.
Depth: [definitions](../lesson_authoring.md#coverage-outline-format). Section IDs below refer to the lesson page.

## Coverage in order

1. **Developed** — Requirements before specifications; matching hardware to a task. (`overview`)
2. **Covered** — Motherboard connections, form factor, sockets and compatibility. (`motherboard`)
3. **Developed** — CPU work, clock speed, cores, threads and cache as selection factors; execution detail belongs in B2/B3. (`cpu-performance`)
4. **Covered** — Heat, throttling, CPU cooling and case airflow. (`cpu-heat`)
5. **Covered** — RAM role, capacity, speed/bandwidth, channels and compatibility. (`memory-performance`)
6. **Covered** — CPU/GPU roles, integrated/dedicated graphics, GPU specifications and VRAM. (`graphics-performance`)
7. **Covered** — Power supply purpose, wattage, efficiency, connectors and case fit. (`psu`)
8. **Covered** — System balance and bottlenecks; storage-performance recap. (`system-balance`)
9. **Covered** — Display suitability: resolution, refresh rate, response time, brightness, contrast and colour. (`display-performance`)
10. **Covered** — Printer suitability: inkjet/laser, DPI, speed, first-page time, duty cycle and running cost. (`printer-performance`)
11. **Developed** — Ports, connector compatibility and transfer limits; transmission methods are taught in E1. (`network-io-performance`)
12. **Covered** — User needs/experience, compatibility, cost, efficiency, implementation, productivity, security and accessibility. (`choice-factors`)
13. **Practice** — Justified recommendations, media-workstation example and budget/compatibility system builder. (`recommendation`)
14. **Practice** — Misconceptions, quick quiz and written application. (`mistakes`)

## Boundaries

Clock speed alone does not determine performance; duty cycle is workload, not speed. Builder products/prices are fictional. Detailed CPU mechanisms and image representation remain in their later lessons.
