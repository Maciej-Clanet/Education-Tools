# Starting a React project

Page: [starting-a-react-project.html](../../pages/topics/starting-a-react-project.html).
Source: [supplied Word document](../word%20documents/Starting%20a%20react%20projec.docx).

Scope: a practical setup/reference lesson in React Frontend. Assumes basic HTML,
CSS and JavaScript; does not introduce React state, props, routing or a backend.

1. **Introduced** — `#before-you-start`: tools, Node/npm checks and prerequisites.
2. **Covered** — `#open-folder`: open the parent projects folder and terminal.
3. **Covered** — `#create-project`: Vite, React and the JavaScript template.
4. **Covered** — `#start-server`: enter the project, install dependencies and run
   the server, including the setup wizard's automatic-start path.
5. **Covered** — `#open-website`: use the actual Local address and recognise the starter.
6. **Covered** — `#restart-server`: stop/restart, distinguish parent and project paths.
7. **Introduced** — `#project-files`: App.jsx, App.css, index.css and index.html.
8. **Developed** — `#replace-app`: a JSX fragment with header/main/footer; no wider
   component design or JSX expression teaching.
9. **Covered** — `#replace-css`: remove starter styles and add the supplied layout.
10. **Developed** — `#layout-explained`: universal reset, :root versus #root,
    column flex layout and a growing main region.
11. **Practice** — `#check-and-troubleshoot`: check the running app and resolve
    common setup problems.

The HTML is the authored source. Snippets contain static syntax spans (JSX/CSS/
shell, initially tokenised with Pygments); no highlighting runtime or build step
is required. Preserve their exact textContent when editing. Shared copy behaviour
