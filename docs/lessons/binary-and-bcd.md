# Binary and BCD

Lesson: [student page](../../pages/topics/binary-and-bcd.html). Unit 2 C1: binary/BCD interpretation and conversion.
Prerequisites: Bits, bytes and powers of two.
Authoring: the linked HTML and its page script.
Depth: [definitions](../lesson_authoring.md#coverage-outline-format). Section IDs below refer to the lesson page.

## Coverage in order

1. **Introduced** — Bit patterns require an interpretation; physical two-state representation. (`overview`)
2. **Covered** — Denary versus binary place values. (`bases`)
3. **Covered** — Binary → denary by active columns; denary → binary by selecting place values; compare directions. (`binary-place-value`)
4. **Practice** — Saved conversion Workshop and scratch table. (`practice-zone`)
5. **Covered** — BCD purpose, four bits per decimal digit and valid 0000–1001 codes. (`bcd`)
6. **Covered** — Whole-number binary versus separately coded decimal digits. (`bcd-compare`)
7. **Covered** — Decimal-display application and BCD storage overhead. (`bcd-display`)
8. **Practice** — Decode digit groups in order and choose the representation rule. (`bcd-decoder`)
9. **Practice** — Misconceptions, recap, quiz and written conversion/application. (`mistakes`)

## Boundaries

No BCD arithmetic or correction-by-six procedure here; arithmetic is a later C1 lesson. Negative/floating-point representation is separate. Fixed examples do not imply arbitrary four-bit groups are valid BCD digits.
