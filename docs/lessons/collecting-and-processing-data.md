# Collecting and processing data

Lesson: [student page](../../pages/topics/collecting-and-processing-data.html). Unit 2 A3: collection, processing functions and their use/implications.
Authoring: the linked HTML and its page script.
Depth: [definitions](../lesson_authoring.md#coverage-outline-format). Section IDs below refer to the lesson page.

## Coverage in order

1. **Covered** — Canteen decision, data → processing → information and applications in different settings. (`overview`)
2. **Covered** — Data origins; manual/hardware collection, suitable capture devices and software-generated logs/telemetry. (`data-collection`)
3. **Covered** — Hardware capture versus software recording; context such as when, where and what. (`hardware-software`)
4. **Introduced** — Raw data and the six processing functions. (`raw-data`)
5. **Covered** — Validation purpose, presence/range/integer/format rules and valid versus accurate; booking lab. (`validation-problem`)
6. **Covered** — Sort complete records while preserving field relationships; weather example. (`sorting`)
7. **Covered** — Change representation/units; worked cases and temperature conversion. (`conversion`)
8. **Covered** — Combine records into summaries; till totals, weather count/mean/maximum and appropriate summary choice. (`aggregation`)
9. **Covered** — Interpret patterns and trends; weather exploration without claiming causation. (`analysis`)
10. **Covered** — Communicate findings for an audience through tables, bars, pie charts and reports tied to source records. (`reporting`)
11. **Practice** — Function comparison, complete data journey and transformation identification. (`recap`)
12. **Practice** — Misconceptions, quiz and written application. (`mistakes`)

## Boundaries

Raw data is unprocessed for the current purpose, not necessarily meaningless. Aggregation does not automatically validate; a pattern does not establish cause. Detailed statistical inference and production data pipelines are outside scope.
