## Coverage in order

1. **Introduced** — Software purpose versus licence/source-code model. (`overview`)
2. **Covered** — Utility purpose; anti-malware, backup, cleanup/storage, defragmentation, compression and encryption utilities. (`utility-software`)
3. **Covered** — Application purpose; productivity, creative/media, communication and specialist categories. (`application-software`)
4. **Practice** — Classify software by its main purpose. (`classify`)
5. **Introduced** — Source code as the foundation for discussing software rights. (`source-code`)
6. **Covered** — Open-source principles, rights, benefits/risks and comparison with proprietary software; distinguish licence, price and total cost. (`open-source`)
7. **Covered** — User/task, technical and organisational selection factors; effects on use and performance. (`choice-factors`)
8. **Practice** — Anti-malware, video-editing and office-suite examples; conditional studio choices and written justification. (`choose-antimalware`)
9. **Practice** — Misconceptions, quick quiz and written tasks. (`mistakes`)

## Boundaries

Defragmentation examples concern appropriate magnetic-drive contexts, not a universal SSD recommendation. Licence conditions differ; open source does not guarantee free support or suitability. Detailed backup/compression/encryption mechanisms belong in later lessons. OS choice remains outside this lesson.
