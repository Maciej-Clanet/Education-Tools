# Flexbox basics

Lesson: [student page](../../pages/topics/flexbox-basics.html). Web Development CSS Basics: parent layout; depth labels refer to this course scope.
Prerequisites: Parent/child relationships, selectors, display, width and height.
Authoring: the linked HTML and its page script.
Depth: [definitions](../lesson_authoring.md#coverage-outline-format). Section IDs below refer to the lesson page.

## Coverage in order

1. **Developed** — Revisit parent/direct children and their initial block layout. (`parent-and-children`)
2. **Covered** — Enable display:flex on the parent. (`switch-on`)
3. **Covered** — Row/column direction and main/cross axes. (`direction`)
4. **Covered** — Main-axis group alignment and space-between distribution. (`justify-content`)
5. **Covered** — Cross-axis alignment; turn direction while preserving axis-based rules. (`align-items`)
6. **Covered** — Stretch with automatic cross-size, and available space needed for visible alignment. (`stretch`)
7. **Covered** — Fixed gap versus distribution of remaining free space. (`gap`)
8. **Practice** — Combine familiar parent properties and edit real CSS. (`put-it-together`)
9. **Practice** — Misconceptions, reference, quiz and written/code application. (`mistakes`)

## Boundaries

Examples assume horizontal LTR writing. Wrapping, flex-grow/shrink, flex presets and align-self are taught in the next lesson. Keep early explanations in parent/child vocabulary; do not hide extra spacing/layout properties inside a preview.
