# Hexadecimal numbers

Lesson: [student page](../../pages/topics/hexadecimal-numbers.html), supporting the Unit 2 number systems sequence.
Prerequisites: Binary place values, binary/denary conversion, bits, nibbles and bytes.
Authoring: the linked HTML, `javascript/pages/hexadecimal-numbers.js` and `css/pages/hexadecimal-numbers.css`.
Depth: [definitions](../lesson_authoring.md#coverage-outline-format). Section IDs below refer to the lesson page.

## Coverage in order

1. **Introduced** — Long binary strings and grouping bits to make them easier to read. (`overview`)
2. **Covered** — Sixteen four-bit patterns and one hex digit per nibble. (`nibbles`, `compact-binary`)
3. **Covered** — Hexadecimal in web colours, memory addresses and byte displays; hex changes the notation, not the stored bits. (`uses`, `memory-addresses`, `raw-bytes`)
4. **Covered** — Base sixteen, symbols 0–9 and A–F, and an interactive single-digit mapping. (`base-sixteen`, `converter`)
5. **Covered** — Hex place values and conversion to denary: find digit values, multiply by place values, then add. Worked examples use 2F and 3A. (`place-value`, `hex-to-denary`)
6. **Covered** — Hex to binary with four bits per digit; binary to hex by grouping from the right. A separate example shows left-padding a short first group. All method steps stay visible. (`conversion-methods`, `binary-to-hex`, `padding-binary`)
7. **Covered** — Denary to hex using binary as a bridge. (`denary-to-hex`)
8. **Practice** — Saved binary/hex conversion workshop with a reference table. (`practice-zone`)
9. **Practice** — Misconceptions, recap, a concept quiz on representation rules and uses, and written explanation/conversion/application. (`mistakes`, `summary`, `quiz`, `exam-practice`)

## Boundaries

Hex is shorthand for binary, not a separate physical storage format. Examples use non-negative whole numbers. Hex arithmetic, signed representations and fractions are outside this lesson. Conversion practice belongs in the workshop and written questions; the quiz checks understanding of the rules.
