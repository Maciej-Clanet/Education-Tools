# Units of digital data

Lesson: [student page](../../pages/topics/units-of-digital-data.html). Unit 2 C1: data units and conversions, with file transfer time as an application.
Authoring: the linked HTML, its page script and page stylesheet. The shared Conversion Stepper supplies the guided byte-prefix conversions.
Depth: [definitions](../lesson_authoring.md#coverage-outline-format). Section IDs below refer to the lesson page.

## Coverage in order

1. **Covered** — A bit as the smallest unit of data, with value 0 or 1. (`bits-and-bytes`)
2. **Covered** — Each additional bit doubles the possible patterns; step through one, two, three and eight bits. (`bit-patterns`)
3. **Covered** — Eight bits per byte; byte, kilobyte, megabyte, gigabyte and terabyte in order. (`unit-ladder`)
4. **Introduced** — Why different units help: example file sizes and drive capacity. (`overview`)
5. **Covered** — Side-by-side decimal and binary systems, highlighted KB/KiB notation, choosing the stated convention, and multiplication/division direction. (`two-systems`)
6. **Covered** — Guided byte-prefix conversions with the shared Conversion Stepper, including multiple steps. (`conversion-stepper`)
7. **Practice** — Saved Conversion Workshop; all tasks appear together in Teacher Slides. (`practice-zone`)
8. **Covered** — MB versus Mb and where each appears; file size versus connection speed and the meaning of /s. (`unit-labels`)
9. **Covered** — Convert bits to bytes by dividing by eight and reverse by multiplying by eight, keeping the prefix. (`same-prefix`)
10. **Covered** — Ideal file transfer time: convert Mb/s to MB/s, then divide the file size in MB by the rate in MB/s. Both worked steps remain visible. (`transfer-time`)
11. **Practice** — Saved transfer-time tasks with separate rate and time answers and calculation feedback. (`transfer-practice`)
12. **Practice** — Concept questions on bits, bytes, unit systems, notation and rates; calculations stay in the workshops. (`quiz`)

## Boundaries

Keep bit/byte notation comparisons after the byte-prefix workshop. Distinguish the fixed eight bits per byte from prefix steps of 1000 or 1024. Respect an explicitly stated exam convention. Transfer times assume a constant rate with no extra data sent; full binary number conversion belongs in the next lesson.

The unchanged conversion tasks retain their existing saved work. Transfer tasks use new response IDs in the existing exam store, whose merge behaviour retains retired written answers. The concept quiz uses a separate answer key/version from earlier quizzes. Retired section links map to the closest current topic. The unlinked comparison copy remains under `pages/reference/` with independent storage.
