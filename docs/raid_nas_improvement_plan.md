# RAID and NAS improvement plan

The September 2026 review calls for a visual first-teaching pass, retaining the
student revision page and the shared lesson/Teacher Slides shell.

## Teaching sequence and review coverage

1. **Frame the lesson** (notes 1–8): shared opener and section dividers; three
   short learning goals; separate single-drive problem and RAID solution;
   clickable RAID-level preview explaining that levels are arrangements, not
   quality rankings. Explain techniques before raw versus usable capacity.
2. **Show the mechanisms** (9–14): labelled file blocks and a looping, pausable
   parallel-reading demonstration; separate mirroring benefits/costs; parity
   versus complete copies; same/different bit comparison before introducing
   XOR; progressive recovery; selectable parity rows and an illustrated rebuild
   sequence. Do not name specific RAID levels in the mechanisms block.
3. **Apply the mechanisms** (15–22): visual technique map; spacious drive trays
   with explicit drive sizes and usable-capacity bars; each RAID level followed
   immediately by a good-fit/poor-fit example. Retain RAID 5 rebuild stages and
   RAID 10 failure interaction. Put formulas in student-only, hover/focus/tap
   capacity details and revision reference, not first-teaching slides.
4. **Make network storage concrete** (23–28): credited, locally stored real NAS
   photograph; labelled cutaway distinguishing interface electronics from the
   Ethernet socket; full-width local/network paths; progressive NAS benefits
   and trade-offs; introduce the server's need before SAN and teach files versus
   blocks using the same named file.
5. **Apply and assess** (29–30): visual drive-failure/deletion/off-site-backup
   comparison; one modal RAID reference; fresh transfer scenarios distinct from
   worked examples. Retain local drafts and quiz progress; remove formula-based
   quiz wording and update quiz version/metadata if questions change.

## Cross-lesson preferences

- Use photographs when real equipment is the learning point; use diagrams when
  showing a process or relationship. Record source, creator, licence and edits.
- Remove teacher prompts from this lesson and make prompt-free slides the default
  for future lesson edits. Keep opener/divider pacing.
