# Stored-program lesson illustrations

The stored-program lesson retains the locally authored `early-computer.svg`.
It is an illustrative patch-cable/switch scene, not a photograph or an exact
reconstruction of ENIAC. Historical context is attributed to the
[Computer History Museum](https://www.computerhistory.org/revolution/story/78).

The lesson diagrams and icons are original HTML/CSS/inline SVG authored for this
project. The earlier stylised micro:bit, Arduino and Raspberry Pi illustrations
have been replaced with the photographs below.

## Photographs added 26 September 2026

Each local JPEG is the 960-pixel-wide rendition supplied by Wikimedia's thumbnail
service. Images were resized by Wikimedia; no local crop, colour adjustment,
compositing or other edit was made. The lesson displays each complete photograph
with its aspect ratio preserved. Credits and licence links appear below the images.
