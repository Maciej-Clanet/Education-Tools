# Image quality teaching derivatives

Generated by `node build-image-quality-lesson.mjs` on 4 October 2026.

`quality-resolution-8.svg`, `quality-resolution-16.svg` and
`quality-resolution-32.svg` are original procedural house-scene illustrations.
Every square stores the colour sampled at its centre from the same mathematical
scene. The SVG rectangles depict a finite grid of stored samples. They are not
an assertion that bitmap files store SVG shapes.

`quality-gradient-1.svg`, `quality-gradient-2.svg`, `quality-gradient-4.svg` and
`quality-gradient-8.svg` have 256 source positions. Each source value is rounded
to the nearest of 2, 4, 16 or 256 evenly spaced grey values respectively.

`quality-grey-1.png`, `quality-grey-2.png`, `quality-grey-4.png` and
`quality-grey-8.png` derive from the shared 960 by 640 `photo-source.png`.
The photograph is by [Korrupt](https://commons.wikimedia.org/wiki/User:Korrupt),
licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
[Original source](https://commons.wikimedia.org/wiki/File:Synology_nas_413j_back_open.jpg).
These derivatives retain the source crop/resize, convert to greyscale and
quantise tones. See [shared credits](CREDITS.md) for the original source and edits.

Reproduction uses ImageMagick 7: convert to Gray, set eight-bit sample precision,
then evaluate `round(u * (2^depth - 1)) / (2^depth - 1)` for each sample, and write
an eight-bit greyscale PNG. These files contain quantised display values and
normal PNG overhead/compression; the file bytes are not a packed-pixel-size
demonstration. ImageMagick reports exactly 2/4/16/256 used shades, respectively.
