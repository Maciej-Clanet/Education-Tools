# Image quality teaching derivatives

Procedural SVGs are generated by `node build-image-quality-lesson.mjs`.
The artwork reference, JPEG comparisons and greyscale PNGs are generated by
`node assets/images/image-representation/build-assets.mjs`. Assets updated
4 October 2026. Use `--skip-images` with the lesson generator when only rebuilding
lesson markup, preserving the measured fixtures and manifest.

`quality-resolution-8.svg`, `quality-resolution-16.svg` and
`quality-resolution-32.svg` are original procedural house-scene illustrations.
Every square stores the colour sampled at its centre from the same mathematical
scene. The SVG rectangles depict a finite grid of stored samples. They are not
an assertion that bitmap files store SVG shapes.

`quality-gradient-1.svg`, `quality-gradient-2.svg`, `quality-gradient-4.svg` and
`quality-gradient-8.svg` have 256 source positions. Each source value is rounded
to the nearest of 2, 4, 16 or 256 evenly spaced grey values respectively.

`quality-grey-1.png`, `quality-grey-2.png`, `quality-grey-4.png` and
`quality-grey-8.png` derive from the shared 960 by 640 `photo-source.png`.
The image is a reproduction of **Gustave Caillebotte, Paris Street; Rainy Day,
1877**, The Art Institute of Chicago. The museum identifies the work as public
domain and releases applicable images under
[CC0](https://www.artic.edu/open-access/open-access-images).
[Museum collection entry](https://www.artic.edu/artworks/20684/paris-street-rainy-day).
These derivatives retain the prepared reference crop/resize, convert to greyscale
and quantise tones. [Shared credits](CREDITS.md) and `quality-artwork.json` record
the actual mirror download, primary rights evidence, exact edits and source hash.

Reproduction uses ImageMagick 7: convert to Gray, set eight-bit sample precision,
then evaluate `round(u * (2^depth - 1)) / (2^depth - 1)` for each sample, and write
an eight-bit greyscale PNG. These files contain quantised display values and
normal PNG overhead/compression; the file bytes are not a packed-pixel-size
demonstration. The available shade counts are 2/4/16/256; ImageMagick reports
2/4/14/220 distinct shades actually used in this image. A picture does not need
to use every possible value. The image is not stretched merely to fill the range.

`photo-source.png` is the prepared 960×640 RGB reference; the three photo JPEGs
encode the same dimensions with fixed 4:4:4 chroma sampling and encoder settings
90, 45 and 8. Those settings are not percentages of retained quality.
`manifest.json` records measured file sizes and greyscale counts/hashes, and the
browser data module is generated from those same files. The procedural sampling
illustrations remain separate original diagrams, while all artwork-based
quality comparisons derive from this one reference image.

The compression close-up is a responsive horizontal band of the full 960×640
decoded image: horizontal centre at x=530, top at y=250. Its visible width and
height depend on the lesson layout. Both comparison sides use identical framing;
the enlargement does not restore detail removed by JPEG compression.
