11 · Collecting and processing data

What is validation?

Validation checks data against predefined rules.

Rule: −30 ≤ value ≤ 55

20°C → ✓ follows rule

91°C → ✗ fails rule

Does valid mean accurate?

20°C ✓ valid … actual temperature: 17°C?

Validation does not prove the data is true.

This range is our teaching station’s rule. Investigate failures; do not invent replacements.

13 · Collecting and processing data

What is sorting?

Sorting changes the order of records using a chosen field.

  1. Before
    11:00 · 09:00 · 14:00 · 10:00
  2. Sort by time, ascending
  3. After
    09:00 · 10:00 · 11:00 · 14:00

Ascending ↑ A–Z / low–high   ·   Descending ↓ Z–A / high–low

Sorting changes record order, not the actual data values. Keep each temperature with its own timestamp.

19 · Collecting and processing data

What is analysis?

Aggregation: 14, 16, 18, 19, 22 → average 17.8°C

Analyse the pattern

Accepted readings rise over time.

Analysis identifies patterns, relationships, trends or anomalies.

A pattern does not establish its cause.

More examples and explanation

Aggregation asks…

What is the average?
The five accepted readings average 17.8°C.

Analysis asks…

What does the data appear to tell us?
The accepted readings rise; the highest accepted value is later in the day. The excluded 91°C is unusual.

Analysis looks for patterns, relationships, trends or anomalies.

“Sales dropped on Tuesday” is an observation. “Sales dropped because it rained” requires additional evidence. A pattern alone does not establish a cause.

Same underlying data, presented for its audience.

Other report formats

Tables · dashboards · written summaries · exception lists

More examples and explanation

Reporting presents processed information in a form suitable for a user or purpose.

Compare conditions

A labelled chart helps weather staff see changes over time.

Find details

A table or printed statement lets someone look up exact values.

Take action

An alert or exception report draws attention to readings needing investigation.

See an overview

A dashboard or summary gives a manager key figures.

The right format depends on the audience and the decision they need to make.

26 · Collecting and processing data


Common exam mistakes


“Data = information”
Reveal the correction
Data is raw; information has meaning or supports a decision.


“Validation proves correctness”
Reveal the correction
It checks rules, not real-world truth.




“Sorting changes the values”
Reveal the correction
It changes record order. Fields stay together.


“Aggregation = analysis”
Reveal the correction
Aggregation summarises values; analysis identifies patterns or meaning.




“Reporting means charts only”
Reveal the correction
Tables, dashboards, alerts and summaries are also reports.


“Collection always needs a person”
Reveal the correction
Sensors and software systems can collect data automatically.

Question 4


Analyse how a college could collect and process attendance data to produce useful information.









Show answer guide



    

  • Teachers could enter attendance in a form, or a reader could capture student IDs; software adds lesson and time.
    • 

  • Validate required IDs/statuses and flag incomplete entries. A valid ID does not prove the student attended.
    • 

  • Sort by student/date; aggregate absences or attendance percentages over a suitable period. Analyse recurring absence patterns.
    • 

  • Report a table or exception summary to tutors so they can follow up. For stronger answers, connect collection choices, processing and decisions; explain that attendance records alone cannot establish reasons for absence.

10 marks



Question 5


A transport company collects GPS, journey-time and passenger data from hundreds of vehicles. Discuss how processing functions could turn raw data into useful information for managers.









Show answer guide



    

  • GPS receivers capture locations; ticketing/passenger systems record counts; software timestamps and links readings to journeys.
    • 

  • Validate plausible locations, times and counts. Flag failures; a value passing validation is not necessarily accurate.
    • 

  • Sort by vehicle and timestamp; convert units or time formats when sources differ so comparisons are meaningful.
    • 

  • Aggregate journey times and passenger counts by route or period. Analyse repeated delays and busy services, then investigate possible causes using further evidence.
    • 

  • Choose reports for managers: route comparisons for scheduling and exception alerts for unusual delays. Link each choice to decisions such as allocating vehicles.
    • 

  • For higher marks, discuss trade-offs: summaries reveal patterns but hide individual journeys; suspect readings can distort averages. Justify selected functions and formats for this purpose rather than listing all six definitions.
