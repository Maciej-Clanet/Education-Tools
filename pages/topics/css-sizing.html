CSS Sizing

The property and unit do different jobs

.card { width: 300px; }
.image { width: 50%; }
.banner { width: 60vw; }

300px is a predictable CSS length. 50% follows the containing block’s width here. 60vw follows the viewport width.

The property tells us what we size. The unit tells us how we measure it.

50% of which space?

.child { width: 50%; }

600px parent × 0.5 = 300px child

In this example, 50% means half the width available from the parent, which supplies the containing block.

CSS Sizing

Responsive means adapting to available space

Responsive design means designing a website so it can adapt to different available screen sizes.

.article { width: 90%; }

The article can shrink. On a very wide screen, it can also become too wide for comfortable reading.

Flexible does not automatically mean ideal. Flexible sizing is one part of responsive design; a later lesson will cover responsive design fully.

CSS Sizing

max-width: give flexible width a ceiling

.article {
  width: 90%;
  max-width: 900px;
}

Shrink with the parent; stop growing at the maximum.

max-width: 900px is an upper limit. It does not force the element to be 900px wide.

CSS Sizing

Watch the maximum take effect

.child { width: 80%; max-width: 600px; }

Parent: 800px

Final child: 600px

800 × 0.8 = 640px requested

Fits inside the parent.

Try parent widths of 400px, 600px, 800px and 1200px. The calculation changes; the final width stops at 600px.

CSS Sizing

min-width: give flexible width a floor

.child { width: 50%; min-width: 300px; }

Parent: 400px

Final child: 300px

400 × 0.5 = 200px requested

Fits inside the parent.

At a 400px parent, 50% requests 200px, so the minimum raises it to 300px. At 1000px, the child can use 500px.

CSS Sizing

Requested size must fit between the limits

.panel {
  width: 500px;
  min-width: 300px;
  max-width: 700px;
}

Minimum = lower boundary. Maximum = upper boundary.

These examples use a minimum that is no larger than the maximum.

CSS Sizing

A minimum can be too large for the space

.card {
  width: 80%;
  min-width: 600px;
}

80% requests 320px → the minimum forces 600px → 200px overflow.

A lower limit can protect content from becoming too narrow. If it is larger than the available space, it can also cause overflow.

A narrower parent

With its normal width otherwise unchanged, the image can keep that width when there is room. Its maximum is the parent’s available width.

CSS Sizing

Min and max work vertically too

.hero { min-height: 100vh; }
.preview { max-height: 120px; }

min-height = floor

At least this high. A naturally sized block may grow taller for its content.

max-height = ceiling

The box stops growing at this limit. Extra content can still overflow.

A height limit does not delete content. Choosing how to handle that overflow comes later.

One viewport high—or at least one viewport high?

Use min-height when “at least this much height” matches the intention.

CSS Sizing

Check the common sizing traps

“50% or 100% means part or all of the browser.”

In these examples, the percentage uses the parent’s available width. That parent may be much narrower than the viewport.

“A parent automatically shrinks any child that is too wide.”

A 500px child can overflow a 300px parent. The child’s sizing rules still matter.

“If I set width, I should also set height.”

Many normal blocks should grow naturally with their content. A fixed height can leave content overflowing.

“max-width: 600px makes the width 600px.”

It sets a ceiling. An element can be narrower, for example when 90% of its parent is only 360px.

“min-width: 300px always starts at 300px.”

It sets a floor. The requested width can already be larger than that.

“min-width always helps responsiveness.”

A minimum larger than the available parent width can cause overflow.

“Responsive design just means using percentages.”

Flexible widths are one part of responsive design. Content, layout and many other choices matter too.

Explain and apply the sizing rules

Write your reasoning before opening the guide. Drafts save in this browser.

1. Explain the overflow

A child has width: 500px inside a parent with width: 300px. Explain why it may overflow and by how much.

Show answer guide

The child requests 500px, which is 200px wider than the parent. The parent does not automatically shrink it.

2. Write suitable CSS

A card should take 80% of its parent’s width but never exceed 600px. Write a rule using the class card.

Show answer guide

.card { width: 80%; max-width: 600px; } The percentage is flexible; the maximum caps it.

3. Compare a size with a limit

Explain the difference between width: 600px and max-width: 600px.

Show answer guide

width requests 600px. max-width sets a ceiling: a smaller requested or naturally available width can still be used.

4. Allow height to grow

A hero should be at least one desktop viewport high but may need more room for content. Write a rule using the class hero.

Show answer guide

.hero { min-height: 100vh; } This gives a viewport-height minimum while allowing natural growth.

5. Explain the responsive connection

Explain how width: 90% with max-width: 800px helps an article adapt to narrow and wide parents.

Show answer guide

On narrow parents, 90% produces a smaller width. It grows as the parent grows, until the 800px maximum caps it. This is one contribution to responsive design.

Glossary

Sizing vocabulary

Parent / child
An element directly containing another element / the element it contains.
Containing block
The box that supplies the sizing reference. In our width examples, the parent’s available content width.
Overflow
Content or a child extending beyond the available space.
Minimum / maximum
A lower limit / an upper limit on a size.
Responsive design
Designing a website to adapt to different available screen sizes.
