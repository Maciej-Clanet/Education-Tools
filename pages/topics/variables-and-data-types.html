Modern Default

Start with const when the value will not be reassigned 

const studentName = "Alex";

console.log(studentName);

Clear Names

A variable name should describe the value

studentNameclear and descriptive
scoreshort but meaningful
gameTitleuses camelCase
isLoggedInreads like a yes/no question

No normal spaces: use studentName, not student name.

camelCase: begin with a lower-case word, then capitalise each new word.

Changing Values

Use let when the variable needs a different value later 

let score = 10;

console.log(score);

score = 15;

console.log(score);
Beforescore → 10
→
Afterscore → 15

The second assignment is score = 15;. Do not repeat let, because the variable already exists.

Decision Guide

Will this variable need a different assigned value later?

Noconst

Use when value will not change.

Yeslet

Use this when reassignment is needed.

Reassigning a const produces an error

A variable declared with const cannot later be assigned a different value.

Code You May See

var is an older way to declare a variable

var message = "Hello";

You may meet var in older code and tutorials.

This course normally uses const and let, which are easier to reason about.

Kinds of Value

JavaScript values can represent different types of data

String"Alex"

Text inside quotation marks.

Number17

A numeric value without quotation marks.

Booleantrue

One of two values: true or false.

Strings represent text

const name = "Alex";
const game = "Space Adventure";
const grade = "A";

Quotation marks show that a value is text. JavaScript has no separate primitive char type: even one character such as "A" is simply a string.

Numbers

Whole and decimal values normally share the number type

const age = 17;whole number
const price = 4.99;decimal number

Both values are JavaScript number values. At this level, JavaScript does not split them into separate integer and float primitive types.

Booleans

Boolean values are either true or false 

const isLoggedIn = true;
const hasPremium = false;
trueboolean

No quotation marks.

"true"string

Quotation marks make it text.

Booleans become especially useful when we later learn comparisons and decisions.

Glossary

Quick glossary

Variable
A name that lets a program refer to a value.
Declare
Create a variable with a keyword such as const or let.
Assign
Give a variable a value.
Reassign
Assign a different value to an existing variable.
String
Text written inside quotation marks.
Number
JavaScript's normal type for whole and decimal numeric values.
Boolean
One of the two values true or false.

Remember

The course rule

  • Use const by default.
  • Use let when reassignment is needed.
  • Put text inside quotation marks.
  • Write booleans without quotation marks.
