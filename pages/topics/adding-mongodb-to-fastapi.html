Keep data after the API stops

Step 1 · Prepare the tools

Start the MongoDB server

  1. Install MongoDB Community Server for your operating system, if necessary.
  2. Follow the start instructions on that installation page.
  3. Keep the server running on this computer at port 27017.

Use a local practice server without database authentication for this lesson. A college computer may already have this server.

MongoDB is the database server. PyMongo is the Python package that communicates with it. MongoDB Compass is an optional viewer.

Install PyMongo in your project

Open the terminal in your backend folder. Activate the virtual environment from the previous lesson.

Terminal · install the driver
python -m pip install pymongo

python -m pip runs the package installer for this Python environment. install pymongo adds the driver.

This command does not install or start the MongoDB server.

Terminal · save the package list
python -m pip freeze > requirements.txt

Run this command in the same environment. It updates the project package list.

Step 2 · Connect Python to MongoDB

Import MongoClient

Create database.py beside main.py. Add this line at the top.

database.py · import
from pymongo import MongoClient
from pymongo
Select the installed PyMongo package.
import MongoClient
Make the MongoClient class available in this file. A class is a template for objects.

This is the only import that database.py needs.

Create the client

database.py · add below the import
client = MongoClient(
    "mongodb://localhost:27017/",
    serverSelectionTimeoutMS=5000
)
client = MongoClient(...)
Create a client object. Store it in client. This object manages communication with MongoDB.
mongodb://
Use the MongoDB connection format.
localhost:27017
localhost means this computer. 27017 is the MongoDB port.

The quoted text is the connection string. The round brackets group the settings across several lines.

Set the server selection timeout

database.py · connection setting
serverSelectionTimeoutMS=5000

5000 milliseconds is 5 seconds.

This setting limits how long PyMongo waits to find a suitable server for a database operation.

If PyMongo cannot find a server, it raises ServerSelectionTimeoutError.

This is not a time limit for every query. Creating the client alone does not confirm that MongoDB is available.

Step 3 · Select the data

Select the database and collection

Add these lines below the client code.

database.py · select the data
db = client["arcane_avenue"]

users = db["users"]
client["arcane_avenue"]
Select the database named arcane_avenue. Store the database object in db.
db["users"]
Select its users collection. Store the collection object in users.

These lines select objects. They do not add a document or load all users into Python.

MongoDB creates the missing database and collection when you first store data or create an index.

Step 4 · Add a rule

Prevent the same email value twice

Add this line below users = db["users"].

database.py · create an index
users.create_index("email", unique=True)
create_index("email", ...)
Create an index on the email field. An index helps MongoDB find documents by that field.
unique=True
Reject an insert or update that would give two documents the same email value.

This line contacts MongoDB. Start the server before you run or import this file.

Know what this index checks

  • An insert with an existing email value raises DuplicateKeyError.
  • The index does not check the email format or who owns the address.
  • By default, upper-case and lower-case letters are different. Keep practice email values in lower case.
  • Creating the index can fail if existing documents have duplicate email values.

Include an email in each practice document. A unique index does not make the field required.

You can run the same index command again. An identical index is reused.

Step 5 · Save the file

Check the complete database.py file

Save this code in database.py, beside main.py.

database.py · complete file

Create

Add one document

Python · add one document
from database import users

result = users.insert_one({
    "email": "luma@example.test",
    "username": "Luma"
})

print(result.inserted_id)

insert_one() stores one document. MongoDB adds a unique _id field if it is absent.

result.inserted_id is the new document ID. Your ID will differ from another student's ID.

Run this example once. A second run with the same email raises DuplicateKeyError.

The document stays in MongoDB after the Python script stops.

Handle a duplicate email

Python · handle a duplicate email
from database import users
from pymongo.errors import DuplicateKeyError

try:
    result = users.insert_one({
        "email": "luma@example.test",
        "username": "Luma"
    })
    print(result.inserted_id)
except DuplicateKeyError:
    print("This email is already in use.")
from pymongo.errors import DuplicateKeyError
Import the error type for a duplicate value in a unique index.
try
Run the insert. If it succeeds, print the new document ID.
except DuplicateKeyError
If the email already exists, print the message. The failed insert does not add another document.

After the first insert, this example prints This email is already in use.

Read

Find one document by email

Python · find one document
from database import users

user = users.find_one({"email": "luma@example.test"})

if user is None:
    print("User not found.")
else:
    print(user["username"])

{"email": "luma@example.test"} is a filter. It selects documents with that exact email value.

find_one() returns one matching document as a dictionary. It returns None when there is no match.

Check for None before you read a field. After the insert, this example prints Luma.

Read several

Read documents with a loop

Python · list documents
from database import users

for user in users.find({}):
    print(user["email"], user["username"])

The empty filter {} matches every document in users.

find() returns a cursor. The loop reads its results one document at a time.

If there are no matches, the loop prints nothing.

Filter, sort and limit a list

Python · list matching documents
from database import users

matches = users.find({"username": "Luma"})

for user in matches.sort("email", 1).limit(5):
    print(user["email"])

The filter selects documents whose username is Luma.

sort("email", 1) puts results in ascending email order. Use -1 for descending order.

limit(5) returns at most five documents.

Update

Change a username

Python · change one document
from database import users

result = users.update_one(
    {"email": "luma@example.test"},
    {"$set": {"username": "Luma Star"}}
)

print(result.matched_count)
print(result.modified_count)

The first dictionary selects the document. $set changes the named field. The email and other fields stay the same.

After the insert, the first run prints 1 and 1: one match and one change.

A second run prints 1 and 0. The username already has that value.

With no match, both counts are 0. This command does not insert a new document.

Delete

Delete one document by email

Python · delete one document
from database import users

result = users.delete_one({"email": "luma@example.test"})

print(result.deleted_count)

delete_one() removes at most one matching document.

deleted_count is 1 if a document was removed. It is 0 if there was no match.

Use a specific filter for changes and deletions. An empty filter matches every document.

This command removes the practice document from MongoDB. To use it again, run the insert example.

Count

Count all or matching documents

Python · count documents
from database import users

total = users.count_documents({})
matches = users.count_documents({"email": "luma@example.test"})

print(total)
print(matches)

The empty filter counts all documents. The email filter counts only documents with that email value.

Each result is a number. The matching count is 0 after deletion and 1 after you insert the practice user again.
