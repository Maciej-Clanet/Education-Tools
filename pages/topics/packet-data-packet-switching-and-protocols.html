Why routes matter

An alternative route can help

Two routes are available

The network has an upper route and a lower route to B.

An upper link becomes unavailable

After routing information updates, packets can use the lower route. Some packets may be lost while the network reacts.

Benefit: a working alternative can keep communication possible. It does not guarantee delivery in every failure.

Communication rules

A protocol is an agreed set of rules for communication.

The devices expect different field orders

Send from A to B.

It reads the addresses the wrong way round.

Use the same rule

Source A | Destination B | Sequence 2 | THE GATE

Both devices agree

They read the same fields in the same way. Rules also specify when to send, confirm receipt or retry.

This invented format shows why shared rules matter. Real protocols specify their own fields and behaviour.

Two useful examples

Different protocols do different jobs

IP · Internet Protocol

Provides addressing and rules for delivering packets across networks. IP alone does not guarantee delivery or arrival order.

TCP · Transmission Control Protocol

Works with IP to provide reliable, ordered data delivery. It uses sequence information, acknowledgements and retransmission.

Application data↔TCP: ordered, reliable delivery↔IP: delivery across networks

An acknowledgement confirms that data was received. Retransmission means sending data again. These protocols work together; they are not alternatives.

Quick recap

Keep the roles separate

Payload is the data piece

The whole packet also has delivery and control information.

Different routes are possible

Packets do not have to use different routes, and delivery is not guaranteed.

Rules control recovery

A check detects a problem. A protocol specifies what happens next.

4 marks Describe

Question 1

Describe the contents of a data packet and explain how those contents help the network and destination system handle the data correctly.

Show answer guide
  • A packet contains payload data plus control details such as source and destination addresses.
  • It may also include sequence or error-checking information.
  • Addressing helps the packet reach the correct destination.
  • Sequence and checking data help the receiver rebuild and verify the original message.
5 marks Explain

Question 2

Explain why a large organisation benefits from packet switching and protocols when many users are accessing the network at the same time.

Show answer guide
  • Packet switching lets many users share the network by sending data as separate packets.
  • Packets can be routed flexibly around busy or failed areas.
  • The receiver can reorder and rebuild the message using packet information.
  • Protocols ensure devices use the same rules for addressing, formatting, and handling packets.
  • Without protocols, devices may receive data but fail to interpret or manage it correctly.

Glossary

Quick glossary

Packet
A chunk of transmitted data with control information.
Payload
The useful message data carried inside the packet.
Packet switching
A method that routes packets independently across a network.
Protocol
An agreed set of communication rules.
Checksum
A value used to check whether data may have changed.

Remember

Data plus rules

  • Packets carry data and handling information.
  • Packet switching routes pieces flexibly.
  • Protocols tell devices how to use those pieces.
