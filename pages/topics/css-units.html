CSS Units

Are these all the same width? 

.box-a { width: 50px; }
.box-b { width: 50%; }
.box-c { width: 50vw; }

Scaled model · viewport: 800 px · containing block: 400 px

50px → 50 px

50% → 200 px

50vw → 400 px

The number tells us how much. The unit tells us what it is measured against.

The viewport is the webpage area inside the browser. The containing block is the width reference surrounding these boxes.

CSS Units

A number usually needs a measurement 

.card {
  width: 50px;
}
50 How much? px Measured against what?

Ask “relative to what?” before choosing the unit.

Does every CSS number need a unit?

No. Non-zero lengths normally need a unit: width: 50; is invalid. A zero length can be written as 0 . Some properties accept numbers, such as line-height: 1.5; .

CSS Units

px: a predictable CSS length

1px border thickness
2px border thickness
4px border thickness
8px border thickness 
.card {
  font-size: 20px;
  border: 2px solid black;
  border-radius: 8px;
}

px means CSS pixels—not necessarily physical screen pixels.

A small predictable border, corner radius or UI detail can be a good fit for px. These are useful choices, not universal rules.

CSS Units

50% follows its containing block 

.card { width: 50%; }

Scaled model · viewport: 800 px · containing block: 400 px

50% → 200 px

Change the parent width. The card stays half as wide.

Percentage accuracy note

What a percentage refers to depends on the CSS property. Here, the card is in normal flow and its containing block is its parent’s content box. We mainly use percentages for widths in this lesson.

CSS Units

rem: one shared root ruler

The root is the <html> element. rem means root em: it uses the root’s font size.

Root → 2rem

2 × 16 px = 32 px

Root → 1rem

1 × root = 16 px

Rulers are enlarged equally to show the relationship.

2rem = 32 px · 0.5rem is half the root size. 

.heading { font-size: 2rem; }
.card { padding: 1rem; }

Text and spacing can share the same root reference and respond when the user’s base text size changes.

About the assumed root size

At an assumed 16px root: 1rem = 16px, 2rem = 32px and 0.5rem = 8px. The controls change a teaching model, not your page settings. Do not routinely override the browser’s root font size just to simplify the maths.

CSS Units

em: use the relevant font-size context

Parent card · font-size: 20px
Child text · font-size: 1.5em

20px × 1.5 = 30px 

.card { font-size: 20px; }
.card p { font-size: 1.5em; }

For font-size, em uses the inherited font size, usually from the parent.

For spacing, the reference is different

For properties such as padding, em uses the element’s own computed font size. It does not simply mean “parent size”.

CSS Units

rem and em can follow different rulers

Root → 2rem

2 × 16 px = 32 px

Local parent → child font-size: 2em

2 × 20 px = 40 px

Rulers are enlarged equally to show the relationship.

2rem = 32 px · child font-size: 2em = 40 px 

.local { font-size: 2em; }
.root-based { font-size: 2rem; }

Change the parent font: em responds. Change the root: rem responds.

In this model the parent has an explicit px font size, so changing the root does not change that parent reference.

CSS Units

The viewport is the visible webpage area

vw measures viewport width. vh measures viewport height.

The viewport is not the whole physical monitor or the entire scrollable document.

CSS Units

vw: follow the viewport width 

.banner { width: 50vw; }

Scaled model · viewport: 800 px · containing block: 400 px

50vw → 400 px

1vw = 1% of viewport width. 50vw = half. 100vw = all of it.

Try a different viewport width. The containing block stays the same, but the banner changes.

CSS Units

vh: follow the viewport height

Scaled viewport: 400 px high

Hero: 50 vh

= 200 px high

The outlined frame is the viewport. The filled area is the hero. 

.hero { height: 50vh; }

1vh = 1% of viewport height. 100vh uses the full height reference.

CSS Units

Half of the parent—or half of the viewport?

Scaled model · viewport: 800 px · containing block: 400 px

50px → 50 px

50% → 200 px

50vw → 400 px

50% follows the containing block. 50vw follows the viewport.

Resize just the containing block, then just the viewport. These widths match only when their references have the same width.

CSS Units

Choose viewport units when the screen is the reference 

.hero { min-height: 100vh; }
.banner { width: 80vw; }

vh → hero section
At least the viewport height, with room to grow for content.

vw → decorative banner
Explicitly based on browser width, independent of a narrow container.

Use % when ordinary content should follow its container. Use vw when the viewport is the intended reference.

The next Sizing lesson explains min-height properly. It allows growth where a fixed height might constrain content.

Mobile viewport note

On mobile, browser controls can change the visible area. Standard vh uses the large viewport reference, so 100vh may extend behind visible controls. Units such as svh, lvh and dvh provide other viewport references; they are extension material, not core quiz content.

Find the wrong measurement

CSS Units

Check the reference before correcting the code

“50% means half the screen.”

For width it normally means half the containing block, which may be much narrower than the viewport.

“50vw is always the same as 50%.”

They only match when the width references match. vw always uses the viewport width reference.

“1px is always one physical screen pixel.”

A CSS pixel is a CSS length. Zoom and display density can change how it maps to physical pixels.

“rem and em are basically the same.”

rem uses the root font size. em uses the relevant local font-size context: inherited size for font-size, own computed size for padding.

“100vh means 100 pixels high.”

It means 100% of the viewport height reference. For a 600px-high reference, 100vh is 600px.

“Relative units mean random sizes.”

They are calculated from a defined reference. Find that reference and the result is predictable.

CSS Units

Relative to what?

px → CSS pixel length border: 2px solid black;
% → Relevant size: containing block for these widths width: 50%;
rem → Root font size font-size: 2rem;
em → Local font-size context padding: 0.5em 1em;
vw → Viewport width width: 50vw;
vh → Viewport height min-height: 100vh;

Match the unit to the reference you want the size to follow.

Question 1

Explain one difference between % and vw. Use a 400px container inside an 800px viewport as an example.

Show answer guide

For width, 50% of this containing block is 200px. 50vw is 400px because it uses the 800px viewport. Name both references.

Question 2

Explain how em and rem differ. Include why em is useful for button padding.

Show answer guide

rem uses the root font size. For font-size, em uses the inherited size; for padding, it uses the element’s own computed font size. The button’s padding can therefore grow with its text.

Question 3

Suggest a unit for a hero that should be at least as tall as a desktop viewport. Then suggest a unit for a card that takes half its container. Explain each choice.

Show answer guide

Use vh for the hero’s viewport-height reference, for example min-height: 100vh. Use % for the card’s containing-block width, for example width: 50%.

Question 4

A student writes .panel { width: 50vw; } and says “This makes it half its parent.” Explain the mistake and suggest a correction.

Show answer guide

50vw is half the viewport width. For half the containing block’s width in this example, use .panel { width: 50%; }. These match only when the two width references match.

Glossary

Useful references

Root
The document’s html element.
Containing block
The box used as the size reference for an element; in our width examples, the parent’s content box.
Viewport
The webpage viewing area inside the browser.
Computed font size
The font size the browser calculates for an element.
