Why can’t I just multiply matching positions?

In our example the first result is (2 × 5) + (1 × 1) = 11. Using only 2 × 5 = 10 leaves out the wraps from Box 2.

Order also matters: A × B and B × A generally give different results. Reversing the order can even make the dimensions incompatible.

Store the same grid

Two indexes locate one value

A 2D array can store the matrix. In this example the first index selects a row, and the second selects a column. Both start at 0.

orders · zero-based indexes
Column 0Column 1
Row 021
Row 143
orders = [[2, 1],
          [4, 3]]

orders[1][0] → 4

Second row, first column. It is the same position we described with row and column numbers starting at 1.

1D array: one index, such as scores[2]. 2D array: two indexes, such as orders[1][0].

Make the connection

Matrix describes the maths; array provides indexed storage

Matrix

A rectangular grid of values with mathematical operations.

“Multiply the 2 × 2 matrix by 3.”

Array

A data structure for storing and accessing elements by index.

“Read or update orders[1][1].”

A 2D array can represent a matrix, but an array can also store other kinds of data. Using an array does not automatically perform matrix operations.

Quick recap

Three checks before you calculate

1. Read the position

Row, then column. Check whether positions start at 1 or indexes start at 0.

2. Check the shape

Addition: same dimensions.

A × B: columns of A = rows of B.

3. Use the right rule

Scalar: every element.

A × B: multiply row–column pairs, then add.

4 marks Explain

Question 1

Explain why a two-dimensional array is a suitable way to store seat occupancy for a theatre with 6 rows and 10 seats in each row.

Show answer guide

A strong answer links the grid layout to indexed access in software.

  • The seating plan has a natural row-and-column structure.
  • Each seat can be stored as one element in a two-dimensional array.
  • The program can access a chosen seat directly using row and column indexes.
  • This keeps the data organised in the same layout as the real seating grid.
5 marks Explain and justify

Question 2

A school stores lesson points in one matrix and club points in another. Both use the same students as rows and the same weeks as columns, in the same order. Explain how the program could calculate total points for each student each week, and why the dimensions must match.

Show answer guide

The best answers explain both the matrix rule and the data meaning behind it.

  • The program can add the matrices element by element.
  • Each position must represent the same student and the same week in both matrices.
  • If the dimensions match, every value has a corresponding value to combine with.
  • The result is another matrix with the same dimensions.
  • If dimensions do not match, some positions will not line up correctly so direct addition is invalid.

Glossary

Quick glossary

Matrix
A grid of values arranged in rows and columns.
Element
One individual value inside a matrix.
Dimension
The size of a matrix, described by its rows and columns.
Two-dimensional array
A structure that stores data using a row index and a column index.

Remember

Think in positions

  • A matrix is the grid itself.
  • A two-dimensional array is one storage method for that grid.
  • Dimension rules decide whether an operation is valid.
