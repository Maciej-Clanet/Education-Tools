What is HTML?

HTML is the markup language used to describe the structure and meaning of content on a web page. Browsers read the HTML and use it to decide what appears on the page and in what order.

Overview

HTML gives a web page its structure

HTML stands for HyperText Markup Language. It is not the part that usually makes a page colourful, and it is not the part that runs calculations or responds to clicks. HTML gives the browser a clear structure: this is a heading, this is a paragraph, this is a list, this is a link, and this is the main content.

The main idea

When you write HTML, you are labelling content so the browser, search engines, screen readers, and other tools can understand what each part of the page is meant to be.

HTML

Defines the page structure and meaning.

CSS

Controls visual style such as colour, spacing, and layout.

JavaScript

Adds behaviour, interaction, and logic.

Tags And Elements

Tags mark where elements start and end

A tag is written inside angle brackets. Many HTML elements use an opening tag, content, and a closing tag. The whole thing is called an element.

Document Structure

Most HTML pages share the same outer shape

A full HTML document starts by telling the browser that it should use modern HTML. The <html> element then surrounds the page, with a <head> for information about the page and a <body> for the content people see.

Head And Metadata

The head describes the page without being the page content

The <head> element contains metadata: useful information about the page. It can include the title shown in a browser tab, a description for search engines, and links to other resources such as stylesheets and scripts.

Metadata still matters

A description does not usually change what the page itself looks like, but it can affect how the page is described in Google and other search results.

Resource links

Stylesheets and scripts are often linked from the head. CSS and JavaScript will become more important once the page structure is solid.

Common Mistakes

Keep these early HTML traps out of your code

These are the mistakes that usually make a first page harder to read, inspect, or fix.

Thinking HTML is styling

HTML describes structure and meaning. CSS does most of the styling work.

Fix: First ask what each piece of content is, then style it later.

Forgetting closing tags

Missing closing tags can make the browser guess where an element ends.

Fix: Check opening and closing tags as pairs unless the element is a void element.

Putting visible content in the head

The head is for metadata and linked resources, not page text the reader should see.

Fix: Put visible page content inside the body.

Using tags only for size

A heading tag is not just large text. It describes a heading in the page structure.

Fix: Choose tags for meaning first. Visual size can be controlled later with CSS.

Glossary

Quick glossary

HTML
Markup language used to structure web page content.
Tag
Text inside angle brackets, such as <p>.
Element
A complete piece of HTML, usually opening tag, content, and closing tag.
Attribute
Extra information written in an opening tag.
Metadata
Information about the page, often stored in the head.
Body
The part of the document where visible page content usually lives.
Semantic element
An element whose name describes the meaning of the content.

Remember

Meaning first

  • HTML labels what each piece of content is.
  • Element order affects page order.
  • The head describes the page; the body contains the page.
  • Use semantic elements when they match the meaning.
