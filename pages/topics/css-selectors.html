HTML creates the elements on a page. CSS can modify them—but first it needs to know exactly which elements we mean. Selectors make that connection.

→

Course rule: when you want to style one or more specific elements, a class is usually the best place to start.

Class Reuse

One class can be reused on many elements

<p class="warning">Your password is incorrect.</p>
<p class="warning">Your session has expired.</p>
<p class="warning">This file could not be opened.</p>
.warning→matches all three
<p class="warning">Warning text</p>
<button class="warning">Delete</button>

A class is not tied to one tag

Both elements possess the warning class, so .warning can match both. It does not mean “warning paragraph”.

Unique Identifiers

ID selectors use a hash

You have already used IDs for page links and form labels. CSS can select an ID too.

HTMLid="contact"No hash inside the ID value
→
CSS#contactThe hash belongs in the CSS selector

Unique means one: an ID should identify one element on a page.

CLASS

Usually best for styling

  • Reusable
  • Works for groups or roles
  • Can be combined with other classes
ID

Identifies one element

  • Should be unique
  • Useful for more than styling
  • Can make later CSS conflicts harder to manage

ID selectors are not forbidden, but they should not be your routine styling tool. Later, you will learn exactly how the browser decides which rule wins.

Broad Selection

Element selectors use the HTML tag name with no prefix

p { ... }matches paragraphs
h1 { ... }matches level-one headings
body { ... }matches the page body

No dot. No hash. Just the element's tag name.

BASE / DEFAULT STYLING

How elements start

Sometimes most or all elements of one type should start with the same general styling. Normal paragraphs might share a basic text appearance and spacing. Pages might share a starting treatment through body.

Meaning: how we want those elements to start unless we deliberately style particular ones differently later.

Ask what you genuinely mean

Every paragraph?pElement selector may be sensible
Only warning paragraphs?.warningUse a class

Element selectors are useful when the intention really applies to that whole element type. Use a class when only particular elements need the role.

Glossary

Quick glossary

Selector
The part of a CSS rule that identifies which HTML element or elements should be affected.
Class
A reusable name that can group elements by a shared role.
ID
A name that should uniquely identify one element on a page.
Element selector
A selector using an HTML tag name, such as p or h1.
Base styling
A broad starting appearance for matching elements.

Remember

Match the prefix

  • Class → dot
  • ID → hash
  • Element → no prefix
  • Spaces separate classes
  • Hyphens join words in one class name
