Template literal recap

Start with a message you already know

const name = "Alex";
const score = 10;

console.log(`${name} has a score of ${score}.`);

Output: Alex has a score of 10. Template literals use backticks. ${...} inserts a value into the string.

Now learn how operators make expressions, how expressions produce values, and how to use those values in calculations and messages.

Familiar operators

You have already used operators

const name = "Alex";

const firstName = "Alex";
const surname = "Smith";
console.log(firstName + " " + surname);

You have used = when giving a variable its starting value, and + when joining text.

Operator

An operator is a symbol that tells JavaScript to perform an operation on one or more values.

Assignment

=

Gives a variable a value.

Joining strings

+

Joins pieces of text, as in the name example.

Expressions

An expression is code that produces a value

  1. Expression5 + 3
  2. Produces the value8

The expression 5 + 3 produces the number 8. You can use that result wherever you need a value.

const total = 5 + 3;

The highlighted 5 + 3 is the expression on the right.

  1. Work out the expression5 + 3
  2. Result8
  3. Assign that result to the variabletotal stores 8

An expression does not need to print anything. Here its result becomes the value stored in total.

Assignment

Work out the right; assign to the left

const score = 10;

= is the assignment operator. In this declaration, it gives score its starting value.

let score = 10;
score = 20;
scorereceives ←20

JavaScript works out the value on the right and assigns it to the variable on the left. Here score now stores 20.

score = 20 is assigning a value, not asking “Is score equal to 20?” In the next lesson we will learn the operators JavaScript uses to compare values.

Numbers vs strings

The type of value changes what + does

Numbers

5 + 3 → 8

With numbers, + performs addition.

Strings

"5" + "3" → "53"

With strings, + performs concatenation: it joins the text.

Quotation marks matter: 5 is a number; "5" is a string. The text joining is the same idea as firstName + " " + surname.

If we need a number, we should deliberately work with a number.

Prompt input

Input that looks like a number can still be text

const number = prompt("Enter a number:");
console.log(number + 5);
  1. User types and submits10
  2. prompt() returns text"10"
  3. The expression"10" + 5
  4. Joined text result"105"

When you submit a prompt, its answer is text. In this example, + joins that text with 5, so the console displays 105. Cancelling a prompt returns null; for these activities, type a value and submit it.

Number conversion

Convert suitable input with Number()

const input = prompt("Enter a number:");
const number = Number(input);

console.log(number + 5);
  1. Submitted input"10"
  2. ConvertNumber(input)
  3. Number value10
  4. Add 515

Number(...) converts a suitable value into a JavaScript number. Now both values in the addition are numbers.

Two readable forms

Separate steps

const input = prompt("Enter a number:");
const number = Number(input);

Store the text first, then convert it.

A shorter form

const number = Number(prompt("Enter a number:"));

Read from the inside out: ask for input, then convert the answer.

Both forms are fine. Use the one you find easier to read.

You may see NaN

Text such as "hello" cannot sensibly be converted to a number. Number("hello") gives NaN: “Not a Number”. The conversion did not produce a usable number.

Using variables

Expressions can use stored values

const price = 4;
const quantity = 3;

const total = price * quantity;
console.log(total);
  1. Expressionprice * quantity
  2. Use the stored values4 * 3
  3. Calculate12
  4. Assign the resulttotal stores 12

JavaScript uses the values stored in price and quantity. The result is a value too, so it can be stored in total.

Expressions in messages

Put an expression inside ${...}

const score = 10;
console.log(`Your next score will be ${score + 5}.`);
  1. Insertion${score + 5}
  2. Use the stored value10 + 5
  3. Evaluate the expression15
  4. Insert its result"Your next score will be 15."

Previously you inserted ${score}. You can also insert the result of an expression such as ${score + 5}. This prints a calculated value; it does not change score.

Remainder

% gives what is left over after division

● ● ●● ● ●● ● ●●1 left over
  1. Share 10 into groups of 33 groups of 3
  2. One is left over10 % 3 → 1

% is the remainder operator. It gives the amount left over after division, not a percentage. 8 % 2 gives 0 because 8 divides evenly into groups of 2.

Later, remainder will help us work out whether numbers divide evenly.

Calculation order

Parentheses can change which calculation happens first

Multiplication first

2 + 3 * 4
2 + 12
14

Multiply 3 by 4, then add 2.

Parentheses first

(2 + 3) * 4
5 * 4
20

Add 2 and 3, then multiply the result by 4.

Like familiar BIDMAS/BODMAS rules, multiplication and division happen before addition and subtraction. Parentheses make a calculation happen first. Operators at the same level are worked out from left to right; % is at the same level as multiplication and division.

Parentheses can also make your intention clearer

const price = 4;
const quantity = 3;
const delivery = 2;

const total = (price * quantity) + delivery;

This produces 14. The parentheses show “items cost, then delivery”. Multiplication would happen first anyway, but the grouping can make the expression easier to read.

Update a variable

Calculate using the old value, then store the new one

let score = 10;
score = score + 5;
console.log(score);
  1. Beforescore stores 10
  2. Calculate on the rightscore + 5 → 10 + 5 → 15
  3. Assign to the leftscore stores 15

The expression uses the old score. Then = replaces it with the result. Use let because this variable needs to be reassigned.

Shorter updates

+= is a shorter form of this update

Expanded form

score = score + 5;

Read the current numeric score, add 5, and store the result.

Compound assignment

score += 5;

The same update in this situation.

score -= 5; // subtract 5 from the score
score *= 2; // multiply the score by 2
score /= 2; // divide the score by 2

These are called compound assignment operators. The expanded form is still fine to use.

Summary

Remember the journey from code to value

Operator

A symbol that performs an operation.

+ - * / % =

Expression

Code that produces a value.

5 + 3 → 8

Assignment

The result on the right goes to the variable on the left.

score = 10;

Arithmetic

Add, subtract, multiply, divide, or find the remainder.

10 % 3 → 1

Types matter

Number addition and string concatenation give different results.

5 + 3 → 8 "5" + "3" → "53"

Numeric input

Convert suitable submitted text into a number.

Number(prompt("Enter a number:"))

Stored values

An expression can use variables.

const total = price * quantity;

Messages

Insert the result of an expression.

`${score + 5}`

Order

Parentheses can change what happens first.

2 + 3 * 4 → 14 (2 + 3) * 4 → 20

Updates

Calculate, then reassign. The shorter form is equivalent here.

score = score + 5; score += 5;

Common mistakes

Check the symbol, the type, and the order

  • = assigns a value; it does not compare two values.
  • Type * for multiplication and / for division.
  • Quoted digits and submitted prompt answers are text. Use Number() when you need numeric input.
  • % gives a remainder, not a percentage.
  • Use parentheses when the addition needs to happen before multiplication.
  • Use let when a variable needs reassignment.

Glossary

Quick glossary

Operator
A symbol that performs an operation.
Expression
Code that produces a value.
Assignment
Giving a variable a value, using =.
Concatenation
Joining strings together.
Number()
Converts a suitable value into a number.
Remainder
The amount left over after division, found with %.
Compound assignment
An operation and reassignment combined, such as +=.

Remember

Work out, then assign

  • Assignment stores that value.
  • For calculations, deliberately work with numbers.
  • Parentheses make your intended order clear.
