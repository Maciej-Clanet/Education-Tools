Overview

Binary arithmetic is normal arithmetic in base 2

The ideas are familiar: add from the right, carry when a column overflows, borrow when subtraction does not have enough, and use place value shifts for multiplication and division. The difference is that every column only has two possible digits: 0 and 1.

Add

When a column reaches 2, write 0 and carry 1.

Subtract

When a column has too little, borrow from the left.

Shift

Left shifts multiply by powers of 2; right shifts divide.

Learning goals

  • Apply the main rules for binary addition.
  • Explain and use borrowing in binary subtraction.
  • Use shifts and partial products for multiplication.
  • Use inverse multiplication ideas for division.
  • Explain why BCD addition may need correction.

Addition

Add from right to left and carry when a column reaches 2

Binary addition works column by column. Because the base is 2, a column cannot write the digit 2. Instead, 1 + 1 becomes 10: write 0 in the current column and carry 1 to the next column on the left.

Worked visual

1011 + 0110

carry 111 top 1011 bottom 0110 result 10001

Two 1s in a column create a carry. The final answer is 10001.

Subtraction

Borrow when the current column cannot subtract

In binary subtraction, 1 - 0 and 1 - 1 are straightforward. The difficult case is 0 - 1. You borrow from the next column to the left, which gives the current column enough value to subtract.

Worked visual

1000 - 0011

Start at the right-hand column.

Step 1 of 5

The 1s column needs to borrow, but the 2s and 4s columns are also 0, so the borrow has to travel from the 8s column.

Multiplication

Multiply with shifts and partial products

Multiplying by 10 in binary shifts a number left by one place, which doubles it. For larger multipliers, write a shifted copy of the first number for each 1 bit in the multiplier, then add the partial products.

Step 1

Look at the multiplier

A 1 bit means "use a copy". A 0 bit means "skip this place".

Step 2

Shift each copy

A copy in the 10 place shifts left once; a copy in the 100 place shifts left twice.

Step 3

Add the partial products

The final multiplication answer is the sum of the shifted copies.

Worked visual

101 x 11

101 x 1 00101 101 x 10 01010 add 01111

The multiplier 11 has two 1 bits, so two shifted copies are added.

Division

Division asks how many times the divisor fits

Dividing by 10 in binary shifts right by one place, which halves a whole-number value. For other divisors, use the inverse of multiplication: find the binary quotient that multiplied by the divisor gives the dividend.

Divide by 2

Shift right once

Each bit moves into the next smaller place value. This halves the number when there is no remainder. This shortcut only works directly for powers of 2 such as / 10 or / 100.

/ 11 or / 101

Try shifted divisors

Shift the divisor left until it lines up with the dividend. If it fits, write a 1 in the quotient and subtract. If it is too large, write 0 and shift right.

Check

Multiply to verify

If divisor x quotient = dividend, the division answer is correct.

Worked visual

10110 / 10

10110 right 1011 22 halves to 11

A right shift removes the lowest place value and moves each remaining bit one column to the right.

Step-through visual

1111 / 11

Dividend 1111 Divisor 11 Quotient --- Remainder 1111

Start with the divisor shifted as far left as it can line up with the dividend.

Step 1 of 5

For divisors like 11 or 101, build the quotient by testing shifted versions of the divisor.

BCD

BCD addition needs correction when a digit goes beyond 9

In BCD, each denary digit is stored as its own 4-bit group. Valid BCD digit patterns are 0000 to 1001. If a 4-bit addition produces 1010 to 1111, or creates a carry, add 0110 to correct the digit.

Worked visual

5 + 7 in BCD

0101 + 0111 1100 invalid digit, add 0110 1 0010 BCD for 12

The raw result 1100 is valid binary, but it is not a valid single BCD digit.

Exam Traps

Common mistakes with binary arithmetic

Forgetting the carry

Binary addition breaks down if the carry is not moved into the next column.

Fix: Write carries above the columns when more than one column overflows.

Borrowing without updating the column

Borrowing changes the column borrowed from, so later work must use the updated value.

Fix: Mark borrowed columns clearly before moving on.

Treating invalid BCD as finished

A result like 1100 is fine in pure binary but is not valid as a single BCD digit.

Fix: Check every BCD nibble is no higher than 1001.

4 marks Explain

Question 1

Describe how carries are used when adding two binary numbers.

Show answer guide
  • Start from the rightmost, least significant column.
  • Add the bits in each column and include any carried bit.
  • If the column total reaches binary 10, write the lower bit and carry into the next column.
  • Continue until every column and final carry has been handled.
6 marks Compare

Question 2

Explain why BCD arithmetic can need a correction step even after normal binary addition has produced a result.

Show answer guide
  • BCD stores each denary digit in a 4-bit group.
  • Valid BCD digit values only run from 0000 to 1001.
  • Normal binary addition can create results above 1001 in one group.
  • Adding 0110 corrects the group into valid BCD and carries into the next digit if needed.

Glossary

Quick glossary

Carry
An extra value moved into the next column during addition.
Borrow
A value taken from the next higher column in subtraction.
Partial product
A shifted copy used during multiplication.
Shift
Moving binary digits left or right by place value.
BCD correction
The extra step used when a BCD digit becomes invalid.

Remember
