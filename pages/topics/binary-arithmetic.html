Binary arithmetic

The place values stay the same

Binary arithmetic uses the same ideas as denary arithmetic. Each column is worth twice the column to its right.

Line up matching place values

5 in binary0101
3 in binary0011

0101 + 0011 = 1000

The same calculation in denary is 5 + 3 = 8.

Keep the columns lined up. Use only 0 and 1 in the final answer.

Addition

When a column reaches two, carry one

0 + 0 = 0

0 + 1 = 1

1 + 0 = 1

Multiplication

Multiply by 10: add one zero on the right

Binary 10 means two. Multiplying by two moves each bit one place to the left.

Read the second number from right to left. A 1 means copy the first number. A 0 means write a zero row.

Division

Divide by 10: shift right once

Binary 10 means two. For a whole-number answer, move each bit one place to the right.

22 divided by 2 gives 11
Place value
(denary)		168421
Start: 2210110
Answer: 1101011

10110 ÷ 10 = 1011

The bit removed from the right is the remainder: 0 for an even number, 1 for an odd number.

Dividing by 100 (four) shifts right twice. Use long division for other divisors.

BCD addition

Check each four-bit digit after adding

BCD stores each decimal digit in four bits. Each group must be from 0000 to 1001 (0 to 9).

Decide whether a group needs correction
After binary additionWhat to do
At most 1001, with no carryKeep the result
Above 1001, or a carry out of the groupAdd 0110 (six)

0011 + 0100 = 0111

3 + 4 = 7. The group is valid and has no carry, so no correction is needed.

Why six? Four bits have 16 patterns, but a BCD digit uses only 10. The difference is 6.

A carry also means correction is needed

Example: 9 + 8. Check the carry even if the low four bits look valid.

  1. 1

    Add in binary

    1001 + 1000 = 1 0001

  2. 2

    1 0001 + 0 0110 = 1 0111

Exam Traps

Common mistakes with binary arithmetic

Forgetting the carry

Binary addition breaks down if the carry is not moved into the next column.

Fix: Write carries above the columns when more than one column overflows.

Borrowing without updating the column

Borrowing changes the column borrowed from, so later work must use the updated value.

Fix: Mark borrowed columns clearly before moving on.

Treating invalid BCD as finished

A result like 1100 is fine in pure binary but is not valid as a single BCD digit.

Fix: Check every BCD nibble is no higher than 1001.

4 marks Explain

Question 1

Describe how carries are used when adding two binary numbers.

Show answer guide
  • Start from the rightmost, least significant column.
  • Add the bits in each column and include any carried bit.
  • If the column total reaches binary 10, write the lower bit and carry into the next column.
  • Continue until every column and final carry has been handled.
6 marks Explain

Question 2

Explain why BCD arithmetic can need a correction step even after normal binary addition has produced a result.

Show answer guide
  • BCD stores each denary digit in a 4-bit group.
  • Valid BCD digit values only run from 0000 to 1001.
  • Normal binary addition can create a group above 1001 or a carry out of the group.
  • Adding 0110 corrects the group into valid BCD and carries into the next digit if needed.

Glossary

Quick glossary

Carry
An extra value moved into the next column during addition.
Borrow
A value taken from the next higher column in subtraction.
Partial product
A shifted copy used during multiplication.
Shift
Moving binary digits left or right by place value.
BCD correction
The extra step used when a BCD digit becomes invalid.
