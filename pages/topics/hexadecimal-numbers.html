Overview

Hexadecimal is a compact way to write binary data

Hexadecimal, often shortened to hex, is a base 16 number system. It uses sixteen symbols: 0 to 9, then A to F. It is useful in computing because one hex digit maps exactly to four binary bits.

16

Base 16

Each place value is sixteen times larger than the one before.

4b

Binary shorthand

Four bits can be replaced by one easy-to-read hex digit.

#F0A

Common in computing

Hex appears in colours, addresses, debugging, and identifiers.

Base 16

Hex needs extra digits after 9

Denary has ten symbols, so it can use 0 to 9. Hexadecimal needs sixteen symbols, so it keeps 0 to 9 and then uses letters A, B, C, D, E, and F for the values 10 to 15.

0123 4567 89AB CDEF

Place Value

Hex place values are powers of 16

Like denary and binary, hexadecimal uses place value. Moving one place left multiplies the value by 16. This is why 2F means 2 x 16 plus 15 x 1, which is 47 in denary.

Hex places

4096s 256s 16s 1s

Example: 2F

2F = (2 x 16) + (F x 1)

F represents denary 15.

Important idea

Letters in hex are still numbers. They are not text characters in the usual sense.

4-Bit Groups

One hex digit matches one binary nibble

A nibble is four bits. Four bits can represent sixteen patterns, from 0000 to 1111. That is exactly the same number of values as one hexadecimal digit, so conversion can be done one group at a time.

0000 = 0 0101 = 5 1010 = A 1111 = F

Conversion

Convert in 4-bit chunks

Hexadecimal to binary

  1. Take one hex digit at a time.
  2. Convert it into a 4-bit binary nibble.
  3. Keep leading zeroes inside each nibble.

Example: 3A becomes 0011 1010.

Binary to hexadecimal

  1. Start from the right and split the binary into groups of four.
  2. Add leading zeroes on the left if the first group is short.
  3. Convert each group into one hex digit.

Example: 1100 0111 becomes C7.

Uses

Hex is used when binary would be too long to read comfortably

Web colours

Colour codes such as #3FA7D6 store red, green, and blue values in pairs of hex digits.

Memory addresses

Addresses are often shown in hex because long binary addresses become shorter and easier to compare.

Debugging and machine code

Low-level tools often display bytes and instructions in hex so patterns are easier to spot.

Identifiers

MAC addresses, IPv6 addresses, and file signatures commonly use hexadecimal notation.

Exam Traps

Common mistakes with hexadecimal

Forgetting that A to F are numbers

A is ten and F is fifteen in hex.

Fix: Keep the digit map nearby until the values feel automatic.

Drops leading zeroes inside a nibble

3 is 0011, not just 11, when converting hex to binary.

Fix: Every hex digit must become four bits.

Groups binary from the wrong side

Binary should be grouped from the right when converting to hex.

Fix: Pad the left side if the first group is short.

4 marks Explain

Question 1

Explain why hexadecimal is often used instead of writing long binary values directly.

Show answer guide
  • One hexadecimal digit represents four binary bits.
  • This makes long binary values shorter to write.
  • Shorter values are easier for humans to read and compare.
  • It can reduce mistakes when copying addresses, bytes, or colour values.
4 marks Demonstrate

Question 2

Describe how to convert 1100 1010 from binary to hexadecimal.

Show answer guide
  • Split the binary into 4-bit groups: 1100 and 1010.
  • 1100 is denary 12, which is hex C.
  • 1010 is denary 10, which is hex A.
  • The hexadecimal answer is CA.

Glossary

Quick glossary

Hexadecimal
A base 16 number system using 0-9 and A-F.
Nibble
A group of four bits.
Base
The number of different digit values used by a number system.
Place value
The value a digit has because of its position.

Remember

Four bits at a time

  • One hex digit equals one 4-bit nibble.
  • Use A-F for denary values 10-15.
  • Group binary from the right when converting to hex.
