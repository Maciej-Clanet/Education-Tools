Overview

Image quality is a set of linked storage decisions

For bitmap images, resolution decides how many pixels are stored. Bit depth decides how much colour information each pixel can hold. Compression decides how the stored data is reduced, and whether image data is preserved exactly.

Resolution

More pixels can store more detail.

Bit depth

More bits per pixel can store more colour values.

Compression

Smaller files can save space and transfer faster.

Learning goals

  • Explain how resolution affects detail and file size.
  • Explain how bit depth affects colours and storage.
  • Compare lossy and lossless compression.
  • Recommend suitable image settings for a scenario.

Quick memory hooks

  • Resolution: how many pixels.
  • Bit depth: how many bits per pixel.
  • Lossless: exact recovery possible.
  • Lossy: smaller file, possible quality loss.

Resolution

Resolution controls how many pixels are stored

Resolution is usually given as width by height, such as 1920 x 1080. A higher resolution stores more pixels, so it can capture more fine detail. It also usually needs more storage because there are more pixel values to save.

Low resolution

Fewer stored samples, less detail, smaller raw data.

Higher resolution

More stored samples, more detail, larger raw data.

Bit Depth

Bit depth controls how many colour values each pixel can store

Bit depth is the number of bits used for each pixel. More bits create more possible values. For example, 1 bit gives 2 values, 2 bits give 4 values, and 8 bits give 256 values for the channel or palette being represented.

Possible values 2 ^ bit depth

More possible values can reduce visible banding in gradients and keep subtle tone changes.

Raw Size

Resolution and bit depth multiply together

Raw bitmap storage can be estimated by multiplying width by height by bits per pixel. Compression and metadata can change the final file size, but this formula explains the basic pressure on storage.

Raw image size in bits width x height x bit depth

Example: 800 x 600 x 24 = 11,520,000 bits, before compression or extra file information.

Compression

Compression reduces file size, but the method matters

Compression makes image files smaller for storage and transfer. The key distinction is whether the original data can be recovered exactly after decompression.

Lossless compression

Reorganises data so the file is smaller, but no original image data is lost. The image can be restored exactly.

Useful for archives, diagrams, medical or legal images.

Lossy compression

Removes some image data to reduce file size more strongly. The original cannot be perfectly restored.

Useful for web photos where smaller files matter.

Trade-Offs

Image choices should match the purpose of the file

Need Likely choice Reason
Small web image Lower resolution or lossy compression Faster loading and smaller transfer size
Detailed print work Higher resolution and suitable bit depth More detail and smoother colour transitions
Exact archive Lossless compression Preserves the original image data
Low storage device Reduced resolution, bit depth, or compression Saves space, but may reduce quality

Exam Traps

Common mistakes with image quality and compression

Mixing up resolution and bit depth

Resolution is about pixel count. Bit depth is about colour values per pixel.

Fix: Ask whether the question is about detail or colour range.

Assuming all compression is lossless

Some compression methods permanently remove data.

Fix: State whether the original image can be recovered exactly.

Ignoring the trade-off

Better quality usually needs more data unless some quality is sacrificed.

Fix: Link image settings to file size and intended use.

4 marks Explain

Question 1

Explain how reducing the bit depth of an image will affect the way the image data is stored and displayed.

Show answer guide
  • Each pixel stores fewer bits of colour data.
  • There are fewer possible colours or shades.
  • The image may show banding, posterisation, or less realistic colour.
  • The raw image data will be smaller.
6 marks Evaluate

Question 2

Evaluate whether lossy or lossless compression is more suitable for storing an important logo archive and a set of quickly loading website images.

Show answer guide
  • Lossless compression preserves the original data exactly.
  • That is useful for an important archive where quality must be preserved.
  • Lossy compression can make website images smaller and faster to load.
  • The trade-off is that some image quality may be lost.

Glossary

Quick glossary

Resolution
The number of pixels used to store the image.
Bit depth
The number of bits used to store each pixel's colour.
Banding
Visible steps between tones when too few values are available.
Lossless compression
Compression that preserves the original data exactly.
Lossy compression
Compression that removes some data to shrink the file.

Remember

Three linked decisions

  • Resolution controls image detail.
  • Bit depth controls colour precision.
  • Compression controls how size is reduced and at what cost.
