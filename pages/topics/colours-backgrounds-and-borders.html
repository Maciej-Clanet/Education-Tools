Precise Colours

One colour can be represented in different formats

Named colours are readable and convenient, but designers often need a more precise choice. This lesson uses four formats only.

NAMEDpurple
RGBrgb(128, 0, 128)
RGBArgba(128, 0, 128, 0.5)
HEX#800080

Named, RGB, and HEX can describe the same visible colour. They are representations, not different categories of colour. You do not need to memorise every named colour.

RGB Channels

RGB mixes red, green, and blue values from 0 to 255

rgb(128, 0, 128)
R redG greenB blue

0 means none of that channel. 255 means its maximum amount.

rgb(255, 0, 0)red
rgb(0, 255, 0)green
rgb(0, 0, 255)blue
rgb(255, 255, 255)white
rgb(0, 0, 0)black
rgb(128, 0, 128)mixed purple

Alpha Transparency

RGBA adds a fourth value for transparency

rgba(255, 0, 0, 0)
0 · fully transparent
rgba(255, 0, 0, 0.5)
0.5 · partly transparent
rgba(255, 0, 0, 1)
1 · fully opaque

background-color: rgba(255, 0, 0, 0.5); makes the background colour partly transparent. The text inside does not automatically become transparent.

Six-Digit HEX

HEX uses three pairs for red, green, and blue

# FF 00 00
redgreenblue

00 is the minimum. FF is the maximum. HEX uses digits 0–9 and letters A–F.

#ff0000red
#00ff00green
#0000ffblue
#ffffffwhite
#000000black

You do not calculate HEX colours by hand. Design tools and colour pickers normally provide the six-digit value for you.

Common Mistakes

Check the property, structure, shape, and readability

Text vs background

color changes text; background-color fills behind it.

CSS spelling

Write color, not the UK spelling colour, in property names.

Visible borders

A border needs a style such as solid.

Complete shorthand

Remember WIDTH + STYLE + COLOUR.

50% is not magic

It forms a circle only when the starting element is square.

Clockwise corners

Four values start top-left and move clockwise.

RGB channels

In today's syntax, each channel uses 0–255, not a percentage.

HEX punctuation

Six-digit HEX values begin with #; use a picker rather than manual conversion.

Accessible meaning

An attractive colour may still be hard to read, and colour alone may hide important meaning.

Glossary

Quick glossary

Background colour
The colour filling the visible area behind an element's content.
Border
A line drawn around an element using a width, style, and colour.
Border radius
A value that rounds one or more corners.
RGB
A colour representation using red, green, and blue channels.
Alpha
The RGBA value controlling colour transparency.
HEX
A colour representation beginning with # and using red, green, and blue pairs.

Remember

Fast memory hooks

  • Border = width + style + colour
  • Radius rounds corners
  • Four values move clockwise
  • RGB channels run 0–255
  • HEX begins with #
  • Meaning needs more than colour
