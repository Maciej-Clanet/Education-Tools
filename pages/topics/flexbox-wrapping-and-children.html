1. Let the parent use another line

A flex row uses one line by default. These cards have a min-width of 96px, so they cannot squeeze smaller. Predict what flex-wrap: wrap will change.

  display: flex; gap: 8px;

2. Keep wrap; change the available room

flex-wrap: wrap stays on. Change only the parent’s width.

Parent .parent · numbered children

1
2
3
4
.parent {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
  width: 420px;
  max-width: 100%;
}

Only the parent’s width changes. Each child keeps its 96px minimum; fewer children fit per line as the parent narrows.

Compare the children’s widths and the room inside the parent.

A narrower parent can fit fewer children on each line.

The parent cannot be wider than the space on your screen. The readout shows its actual inside width. All four children still keep the same HTML order.

Does wrapping change row into column?

No. This is still a row layout. Children go across each line, then continue on the next line. The 8px gap also separates the lines.

3. A child can have its own Flexbox rules

The first lesson mostly put rules on the parent. A flex child can also have rules that control its own size or alignment.

Rules on the parent

Arrange the children together.

display: flex
flex-wrap
gap
align-items

Rules on a child

Control how that child takes part.

flex-grow
flex-shrink
flex
align-self

Being a flex child does not automatically give it display: flex.

A flex child is often called a flex item. It can use child properties because of its parent’s layout. Those properties do not turn on Flexbox for its own contents.

5. Let one child take the extra room

flex-grow controls whether a child takes a share of spare main-axis space. These children start at 64px wide. Change child 2 from 0 to 1.

Parent .parent · numbered children

1
2
3
.parent { display: flex; gap: 8px; }
.child { width: 64px; }
.child-two { flex-grow: 0; }

Grow 0 is the default. None of these children takes the spare main-axis space.

Compare the children’s widths and the room inside the parent.

flex-grow: 0 leaves spare room. flex-grow: 1 lets this child use it.

The dotted marker shows the original 64px width. Growth changes the child’s width; it does not add to the gap or turn the child into a flex parent.

6. Share the extra room between children

All three children now grow. Keep children 1 and 3 at flex-grow: 1; change only child 2’s share.

Parent .parent · numbered children

1
2
3
.parent { display: flex; gap: 8px; }
.child {
  width: 64px;
  flex-grow: 1;
}
.child-two { flex-grow: 1; }

All three start at 64px and receive equal shares of the extra room.

Compare the children’s widths and the room inside the parent.

A grow factor compares shares of extra space, not final widths.

Predict: does grow 2 make child 2 twice as wide?

No. Each child already starts at 64px. With factors 1 : 2 : 1, child 2 gains twice as much extra width as either neighbour, then keeps its original 64px too.

7. What if the children ask for too much room?

Each child asks for width: 120px. Keep their rules the same, then make the parent tighter.

Parent .parent · numbered children

1
2
3
.parent {
  display: flex; gap: 8px;
  width: 420px;
  max-width: 100%;
}
.child {
  width: 120px; min-width: 0;
  flex-shrink: 1;
}

Shrink 1 is the default. When the parent is too narrow, these equal-size children share the shortage. They stay on one line.

Compare the children’s widths and the room inside the parent.

flex-shrink: 1 is the default: the child can give up main-axis space.

These short-label boxes use min-width: 0 so they can become narrower. Real content and minimum sizes can limit how far a child shrinks.

Why can a child end up narrower than its width declaration?

Here, 120px is the requested starting width. Flexbox reduces it when the row is short of space and shrinking is allowed. The gap remains 8px.

8. Keep one child from shrinking

Child 2 should keep its 120px width. Change only its flex-shrink value to 0.

Parent .parent · numbered children

1
2
3
.parent { display: flex; gap: 8px; }
.child {
  width: 120px;
  min-width: 0;
  flex-shrink: 1;
}
.child-two { flex-shrink: 1; }

All three have the same starting width and shrink factor, so they give up equal amounts of width.

Compare the children’s widths and the room inside the parent.

flex-shrink: 0 stops this child giving up width.

Do all children always lose equal amounts?

No. Shrinking takes both the shrink factor and the starting size into account. With the same factor, a larger starting size normally gives up more space. This example uses equal starting widths to make the comparison clear.

9. What if nobody can shrink?

The parent still uses nowrap. Now change the shrink setting on every child.

Parent .parent · numbered children

1
2
3
.parent {
  display: flex; gap: 8px;
  flex-wrap: nowrap;
}
.child {
  width: 120px; min-width: 0;
  flex-shrink: 1;
}

The children can shrink to fit this parent. Shrinking changes widths; wrapping would put children on another line.

Compare the children’s widths and the room inside the parent.

If children cannot shrink and cannot wrap, they may overflow.

Shrinking changes a child’s size. Wrapping moves a child onto another line. These are different ways to respond to limited room.

10. Choose a combined flex setting

flex is a shorthand for a child’s flexible sizing. Try these two useful settings, then compare a roomy parent with a tight one.

Parent .parent · numbered children

1
2
3
.parent { display: flex; gap: 8px; }
.child {
  width: 120px;
  min-width: 0;
  flex: auto;
}

flex: auto allows both growth and shrinking. The 120px width is the starting point; the available room determines the final width.

Compare the children’s widths and the room inside the parent.

flex: auto can grow and shrink. flex: none does neither.

Both use the child’s width, or its content when width is automatic, as the starting point. The flex property belongs on the child; display: flex belongs on the element arranging children.

How does this relate to the separate properties?

For these examples, flex: auto uses grow 1 and shrink 1; flex: none uses grow 0 and shrink 0. The shorthand also sets how sizing starts, so treat it as a complete setting rather than mixing in earlier grow/shrink rules.

11. Use flex: 1 for a simple shared row

These children have different width declarations. Compare flex: auto with flex: 1 on all three.

Parent .parent · numbered children

1
2
3
.parent { display: flex; gap: 8px; }
.child { min-width: 0; flex: auto; }
.child-one { width: 80px; }
.child-two { width: 160px; }
.child-three { width: 80px; }

flex: auto starts from the different widths, then lets the children grow or shrink to fit. Child 2 remains wider than its neighbours.

Compare the children’s widths and the room inside the parent.

flex: 1 is a useful equal-sharing recipe for simple, matching children.

It shares from an equal starting point instead of preserving the different starting widths in this example. Long content, padding and minimum sizes can affect the final result.

Is flex: 1 just a shorter way to write flex-grow: 1?

No. flex: 1 also permits shrinking and changes how sizing starts. Setting only flex-grow: 1 keeps the existing starting widths and shares the extra space.

12. Give one child its own cross-axis alignment

The parent sets align-items: flex-start. Use align-self on child 2 to give it a different position.

Parent .parent · numbered children

Main axis
Cross axis · align-self
1
2
3
.parent {
  display: flex;
  align-items: flex-start;
  gap: 8px;
}
.child-two {
  align-self: auto;
}

auto follows the parent’s align-items setting: all children start at the top.

align-items sets the parent’s default. align-self sets one child’s choice.

auto follows the parent. Child 2 has automatic width and height, with 48px minimums, so stretch can fill the cross axis. The other children keep fixed sizes.

Does this centre the text inside child 2?

No. It aligns the child’s box within the parent’s flex line. Arranging the child’s own contents is a separate job.

13. The child still follows the cross axis

Keep align-self: center on child 2. Change only the parent’s direction.

Parent .parent · numbered children

Cross axis · align-self

  flex-direction: row;

In a row, the cross axis is vertical. Child 2 centres top to bottom; the others stay at the top.

In a column, align-self works left to right in these examples.

The main and cross axes come from the parent’s flex-direction. Child 2 remains second in the HTML and in the sequence.

16. Catch the common mistakes

“Every flex child gets display: flex.”

A child becomes a flex item because of its parent. Set its own display: flex only when you want it to arrange its direct children with Flexbox.

“Grow 2 means twice the final width.”

Grow compares shares of extra space. The starting sizes still matter.

“Shrink 0 guarantees that everything fits.”

It prevents that child shrinking. Other children must give up more space, or the layout may overflow.

Check which job each rule does

“flex: 1 and flex-grow: 1 are identical.”

The shorthand also sets other sizing behaviour. Use its complete recipe; it is more than the grow factor alone.

“align-self centres a child along the main axis.”

It uses the cross axis. It also aligns the child’s box, not the text inside it.

“Wrap makes a fixed grid of matching columns.”

Each flex line shares its own space. Growing children on a shorter final line can become wider.

3. Predict which child shrinks

Three children each start at 120px wide in one flex row. The parent becomes too narrow for all three. Children 1 and 3 use flex-shrink: 1; child 2 uses flex-shrink: 0. Explain what happens, and one reason the row might still overflow. (3 marks)

One mark each: child 2 keeps its starting width; children 1 and 3 can give up space; if their content or minimum sizes prevent enough shrinking, the row can still overflow. A parent narrower than child 2 alone can also force overflow.

Key terms

Flex parent / container
An element with display: flex that arranges its direct children.
Flex child / item
A direct child taking part in its parent’s flex layout.
Wrapping
Allowing children to continue onto another flex line.
Grow factor
A child’s share of extra main-axis space.
Shrink factor
A child’s participation in giving up main-axis space when needed; starting size also matters.
flex shorthand
A combined setting for a child’s flexible sizing.
align-self
A child’s own choice of cross-axis alignment.
Nested flex parent
A flex child that also has display: flex to arrange its own children.
Overflow
Content extending beyond the parent’s available space.
