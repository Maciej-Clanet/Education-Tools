01 · Digital data units

Why do we need different units?

Illustrative sizes; actual files and devices vary.

They all measure data. Different-sized units make very different amounts easier to describe.

Revision notes

Files, memory and storage can hold very different amounts of data. Units help us compare file sizes, choose storage and interpret connection speeds. The underlying amount does not change when we express it in a different unit.

02 · Digital data units

One bit stores one binary state

0OFF / low state
or
1ON / high state

A bit is a binary digit: either 0 or 1.

Two states shown conceptually; a bit is not necessarily a literal switch.

Revision notes

Binary states can stand for off/on, false/true, no/yes or low/high voltage. Patterns of bits can represent numbers, text, images, audio and instructions. We study how particular patterns represent values in later lessons.

03 · Digital data units

Each extra bit doubles the possible patterns

1 bit → 2 possible patterns
01

Each position can be 0 or 1, doubling the combinations.

Revision notes

1 bit gives 2 patterns; 2 bits give 4 (00, 01, 10, 11); 3 bits give 8; 8 bits give 256. The final jump adds five bits, so doubles five times. There is no need to list all 256 patterns.

04 · Digital data units

Eight bits form one byte

01000001

└── One group of eight ──┘

8 bits = 1 byte

b = bitB = byteMb ≠ MB
Revision notes

A byte is a group of eight bits. File sizes, storage capacity and memory capacity are commonly described in bytes and their multiples. In these unit symbols, lowercase b means bit and uppercase B means byte. The pattern shown is just one of 256 possible byte patterns.

Moving right reaches a larger-sized unit; moving left reaches a smaller-sized unit. The bit/byte boundary uses 8. The other adjacent boundaries change the prefix and use the chosen scale. KB and KiB are labels from different systems, not interchangeable names.

06 · Digital data units

  3. 1 GB = 1000 MB

1 MB = 1,000,000 B · 1 GB = 1,000,000,000 B

Decimal prefixes are common in drive specifications, networking and product descriptions.

Revision notes

This lesson uses the familiar label KB for a decimal kilobyte (also written kB). Each prefix step changes the size of the unit by 1000. The separate 8-bit byte relationship still applies.

Ten doublings give 1024. The i in KiB / MiB / GiB identifies binary prefixes.

Revision notes

KiB is kibibyte; MiB is mebibyte; GiB is gibibyte; TiB is tebibyte. Powers of two are useful in computing. Detailed binary place values and arithmetic belong to the later binary lessons.

Revision notes

Some software and questions use KB/MB/GB labels while intending steps of 1024. Those labels are not formally interchangeable with KiB/MiB/GiB, but a stated question convention takes priority for that calculation. If no convention is supplied, use decimal prefixes for KB/MB/GB and binary prefixes for KiB/MiB/GiB.

10 · Digital data units

Walk the route: 3.5 GB → MB

Decimal convention · reveal one part of the method at a time.

Revision notes

GB → MB is one step to a smaller unit, so multiply by 1000. 3.5 × 1000 = 3500 MB. The unit became smaller and the number larger, while the amount stayed the same.

11 · Digital data units

Walk the route: 4096 MiB → GiB

Binary prefixes already tell us to use 1024.

Revision notes

MiB → GiB is one step to a larger unit. 4096 ÷ 1024 = 4 GiB. Larger units need a smaller number.

12 · Digital data units

Take each jump before using a shortcut

2 GiB → KiB · two prefix steps, both binary.

Revision notes

2 GiB × 1024 = 2048 MiB. Then 2048 MiB × 1024 = 2,097,152 KiB. After walking both steps, the shortcut is 2 × 1024². Do not apply just one multiplication when there are two steps.

13 · Digital data units

Bits ↔ bytes uses 8

80 Mb → MB · the prefix stays mega.

Reverse it: 10 MB → Mb

10 × 8 = 80 Mb. Byte to bit means eight times as many smaller units.

Revision notes

8 bits = 1 byte at every matching prefix. 80 Mb ÷ 8 = 10 MB. This relationship does not need a choice between 1000 and 1024. Always read the final letter before calculating.

14 · Digital data units

One route can use two different rules

16 Mb → KB · assume decimal prefix steps.

Revision notes

First 16 Mb ÷ 8 = 2 MB: a bit/byte step. Then 2 MB × 1000 = 2000 KB: a prefix step. Dividing at the first boundary and multiplying at the second is correct; follow the individual relationships.

Capacity is an amount, not a speed. File, drive and memory quantities can all be expressed in bytes and their multiples. This 80 MB file size is illustrative.

Megabits per second · a rate, not a stored amount.

Revision notes

Transfer rate describes data moved per unit of time. Network speeds are often in bits per second while file sizes are commonly in bytes. MB/s is megabytes per second; Mb/s is megabits per second. Both the final letter and the /s matter.

19 · Digital data units

Match the units before finding the time

File: 800 MBConnection: 80 Mb/s

1 · Match bits and bytes
80 Mb/s ÷ 8 = 10 MB/s

2 · Divide size by rate

800 MB ÷ 10 MB/s = 80 seconds. The byte units match, leaving time in seconds.

Idealised constant rate; real transfer time may be longer because of overhead and changing speeds.

Revision notes

Time = amount of data ÷ transfer rate, using matching data units. Here converting the rate first prevents the mistaken answer of 10 seconds. The calculation assumes the full stated rate is available throughout.

20 · Digital data units

Spot the unit mistake

“b and B mean the same thing.”

b means bit; B means byte. Read the final letter first.

“Every ladder step uses 1000 or 1024.”

Bit ↔ byte uses 8. Only prefix steps use the chosen base.

“KB and KiB are formally identical.”

KB denotes a decimal kilobyte here; KiB is a binary kibibyte. Follow an explicitly stated question convention.

“A larger unit means a larger number.”

For the same positive amount, larger pieces mean fewer pieces, so the number decreases.

“80 MB is the same as 80 Mb.”

80 MB = 640 Mb. Eight bits make each byte.

“The final number is enough.”

Include the target unit, and use /s for a rate. A unitless answer loses meaning.

4 marks Explain

Question 1

Explain what a bit is and why patterns of bits are important in a computer system.

Show answer guide
  • A bit is a binary digit.
  • It can hold one of two values, 0 or 1.
  • These values can represent states such as off/on or false/true.
  • Patterns of bits can represent numbers, text, images, sound, instructions, and other data.
6 marks Explain and apply

Question 2

A student needs to convert between digital data units. Explain how they should decide whether to multiply or divide, and how they should choose between the decimal and binary systems.

Show answer guide
  • First identify the starting unit and target unit.
  • Count the steps between them on the unit ladder.
  • Moving to a larger unit means divide; moving to a smaller unit means multiply.
  • Use 1000 for decimal units or when the question says to use 1000.
  • Use 1024 for binary units, KiB/MiB/GiB labels, or when the question says to use 1024.
  • Include the final unit with the answer.
  • Use 8 for a bit/byte boundary; 1000 or 1024 applies only to prefix steps.
6 marksCalculate and explain

Question 3

Explain how a byte differs from a bit. Convert 3.5 GB to MB using decimal units, then convert 4096 MiB to GiB. Show each operation.

Show answer guide

A byte is eight bits. 3.5 × 1000 = 3500 MB; the unit becomes smaller. 4096 ÷ 1024 = 4 GiB; the unit becomes larger. Give the final units and link multiplication/division to the number of pieces.

6 marksShow the method

Question 4

Convert 2 GiB to KiB, showing the intermediate unit. Then convert 16 Mb to KB using decimal prefixes and identify the two different relationships.

Show answer guide

2 GiB → 2048 MiB → 2,097,152 KiB (×1024 twice). 16 Mb → 2 MB (÷8), then → 2000 KB (×1000). The first mixed step changes bits to bytes; the second changes prefix.

6 marksApply and explain

Question 5

A file is 800 MB and a connection transfers at 80 Mb/s. Explain the difference between these quantities, then estimate the ideal transfer time. State an assumption.

Show answer guide

800 MB is a data amount; 80 Mb/s is megabits per second. 80 ÷ 8 = 10 MB/s. 800 ÷ 10 = 80 seconds. Assume a constant full transfer rate with no additional overhead; actual time can be longer.

Glossary

Quick glossary

Bit
The smallest binary unit, holding 0 or 1.
Byte
A group of 8 bits.
Decimal units
Byte prefixes that scale by 1000, such as KB, MB and GB.
Binary units
Byte prefixes that scale by 1024, such as KiB, MiB and GiB.
Bandwidth
The amount of data that can move per second.

Remember

Read the final letter

  • b means bits and B means bytes.
  • Decimal and binary systems use different step sizes.
  • Unit conversion should happen before the calculation.
