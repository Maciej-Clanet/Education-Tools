Overview

What you should know by the end of this lesson

Digital data units tell us how much information is being stored, processed, or transmitted. The key skill is not memorising a long list of labels; it is knowing what the smallest unit means, how units scale up, and which conversion system the question is using.

Smallest unit

Bits

One binary state, written as 0 or 1.

Useful group

Bytes

Eight bits grouped together for storage and file sizes.

Two systems

1000 or 1024

Decimal units use powers of 1000; binary units use powers of 1024.

Learning goals

  • Explain what a bit is and why bits matter.
  • Describe how data units progress from bits to terabytes.
  • Separate decimal and binary unit systems.
  • Use a reliable strategy for unit conversions.

Why it matters

Hardware specifications, file sizes, memory capacity, image sizes, and network speeds all rely on these units. If you confuse bits with bytes, a final answer can be eight times too large or too small.

Foundations

A bit is one binary state, and patterns of bits represent data

A bit is a binary digit. It can hold one of two possible values: 0 or 1. Those values can stand for different pairs of states, such as off/on, false/true, no/yes, or low/high voltage. A single bit is tiny, but patterns of many bits can represent numbers, text, images, audio, and instructions.

1 on / true / yes

A byte is a group of eight bits. Bytes are useful because file sizes, storage capacity, and memory capacity would be awkward to describe one bit at a time.

Progression

Units grow in a ladder from small values to large storage sizes

Each step to the right is a larger unit. Each step to the left is a smaller unit. The multiplier for each step depends on which system the question is using: decimal or binary.

bit b One binary state
byte B 8 bits
kilobyte KB / KiB Thousands of bytes
megabyte MB / MiB Images, audio, documents
gigabyte GB / GiB Apps, videos, storage
terabyte TB / TiB Large drives and backups

Moving to a larger unit

Divide once for each step along the ladder.

Moving to a smaller unit

Multiply once for each step along the ladder.

Decimal and Binary

There are two common systems for larger digital data units

Decimal units use powers of 1000. Binary units use powers of 1024. Both appear in computing, and both can be valid depending on the question, device, or software context.

Decimal

Base 1000

  • 1 KB = 1000 bytes
  • 1 MB = 1000 KB
  • 1 GB = 1000 MB

Often seen in storage marketing, networking contexts, and simpler classroom tasks.

Binary

Base 1024

  • 1 KiB = 1024 bytes
  • 1 MiB = 1024 KiB
  • 1 GiB = 1024 MiB

Based on powers of two. In many lessons and tools, KB, MB, and GB are still used even when the intended base is 1024.

How to decide which one to use

If the question says KiB, MiB, or "use 1024", use the binary system. If the question says "use 1000", use the decimal system. If the context is unclear, state your assumption before calculating.

Strategy

Use a repeatable method instead of guessing the operation

Most conversion mistakes happen before the arithmetic starts. Slow down, read the units, choose the system, then move along the unit ladder one step at a time.

1

Read the unit

Check whether the value is in bits or bytes.

2

Choose the base

Use 1000 for decimal or 1024 for binary.

3

Count steps

Find how many spaces you move on the unit ladder.

4

Multiply or divide

Smaller unit means multiply; larger unit means divide.

5

Write the final unit

The number is incomplete without the unit.

Example: moving to a larger unit

2048 KB to MB is one step right. In binary, divide by 1024, so the result is 2 MB.

Example: bits to bytes

A rate in Mb/s must be divided by 8 before comparing it with a file size in MB.

Interpretation

Storage capacity and transfer rate use similar units for different ideas

Capacity tells you how much data can be stored. Transfer rate tells you how quickly data moves. Network speeds are often written in bits per second, while file sizes are usually written in bytes.

Capacity

How much fits?

A file size of 80 MB describes how much storage space the file uses.

Rate

How fast does it move?

A connection speed of 80 Mb/s describes how much data can move each second.

Warning

Compare like with like

Convert bits to bytes, or bytes to bits, before estimating transfer time.

Exam Traps

Common mistakes with digital data units

These marks are often lost through careless unit handling rather than difficult theory.

Mixing up bits and bytes

Many students read the prefix and miss the final letter. Mb and MB are not interchangeable.

Fix: Underline the unit first, then convert before you calculate.

Using 1000 or 1024 without checking

Decimal and binary unit systems give different numbers, so the base must match the question.

Fix: Look for 1000, 1024, or binary unit labels such as MiB.

Leaving the answer unitless

A number on its own is incomplete in data-size questions.

Fix: Always include the final unit, such as MB, Gb, or seconds.

A student needs to convert between digital data units. Explain how they should decide whether to multiply or divide, and how they should choose between the decimal and binary systems.

Show answer guide
  • First identify the starting unit and target unit.
  • Count the steps between them on the unit ladder.
