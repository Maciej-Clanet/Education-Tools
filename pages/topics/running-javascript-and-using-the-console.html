New Language

JavaScript gives the computer instructions

You have already used HTML to describe content and CSS to control appearance. JavaScript is the language we use to give instructions that can make things happen.

HTML Content and structure

Headings, paragraphs, links, images, and forms.

CSS Appearance and layout

Colours, spacing, borders, fonts, and positioning.

JavaScript Instructions and behaviour

Code that can run, make choices, handle data, and react.

What JavaScript can do later

  • Perform calculations
  • Make decisions
  • Repeat tasks
  • Work with data
  • Respond when someone interacts with a page

Where we begin today

We will start with the console so you can focus on the JavaScript instructions themselves.

Edit code -> press Run -> read the Console.

Execution Order

JavaScript normally runs from top to bottom

  1. Top
  2. console.log("First");
  3. console.log("Second");
  4. console.log("Third");
  5. Bottom

Expected console output

First
Second
Third

Text version: the first instruction runs first, then the second, then the third.

JavaScript Playground

The basic workflow is edit, run, output

1Read or change the code
2Press Run
3JavaScript executes
4Read the Console

The Run button executes the JavaScript currently in the editor. If you change the code, press Run again to see the new result.

Console Output

The console helps programmers see messages, results, and errors

The console is for development

Programmers use it while building and testing code. It is not normally the final screen ordinary website visitors use.

console.log() sends information there

For now, the content between quotation marks is simply the text we want to output.

When we write text directly in JavaScript like this, we put it inside quotation marks.

Code Notes

Comments are notes for people reading the code

// This is a comment

JavaScript ignores a single-line comment when it runs the program.

console.log("Program started");

This line is an instruction, so it can send output to the console.

Console Commands

Use different console messages for different purposes

Normal message console.log("Program started");

Use this for ordinary output, results, and checks.

Warning message console.warn("Battery is low");

Use this when something may need attention.

Error-style message console.error("Could not load the file");

Use this to display a message about something going wrong.

console.error() displays an error-style message, but it does not by itself stop the program.

Clear Output

console.clear() clears earlier console messages

1Messages are added
2console.clear(); runs
3Earlier messages are removed
4The next instruction still runs

If code appears after console.clear();, JavaScript carries on and can add new output.

First Error Message

The console can help when JavaScript cannot understand code

Broken 
console.log("Hello";

The command is not complete, so JavaScript reports an error.

Fixed 
console.log("Hello");

The command is complete, so the console can display Hello.

Error messages are useful information. They can help you find the part of the code that needs attention.

Debug Lab

Fix one small console command

Experiment

Make a few changes and run the code after each one

  1. Change the normal message.
  2. Add another console.log() line.
  3. Move the warning to the top.
  4. Add a comment above one line.
  5. Add console.clear(); before the final message.

Glossary

Quick glossary

JavaScript
A programming language that gives instructions to execute.
Run
Execute the JavaScript currently in the editor.
Console
A place to see output, messages, and errors while developing.
Comment
A note for people reading code. JavaScript ignores it.
Output
Information the program sends somewhere, such as the console.

Remember

The pattern

  • Read or change the JavaScript.
  • Press Run.
  • Watch the Console.
  • Use errors as clues.
