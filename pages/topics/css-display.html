CSS Display

Choose HTML for meaning, CSS for presentation

HTML

<a class="menu-link" href="index.html">
  Home
</a>

A link provides a destination.

CSS

.menu-link {
  display: block;
}

The same link now starts a new line.

Changing display does not change the element’s HTML meaning.

Do not choose a div just to get a new line, or a span just to put things beside each other. Use the element that suits the content.

Block: normally start a new line

.item { display: block; }

Consecutive blocks normally stack. With its automatic width, a normal block generally uses the available width.

Block describes behaviour in flow—not a width of 100%.

Familiar defaults: p, h1 and div. CSS can change these behaviours.

CSS Display

Inline: join the line of content

Text before One Two Three text after.
.item { display: inline; }

Inline content does not normally force a new line. It participates in the surrounding line and can wrap when space runs out.

Familiar defaults: a, span and strong. Their HTML meanings still guide when to use them.

CSS Display

Why does this width seem to do nothing?

.label {
  display: inline;
  width: 300px;
  height: 100px;
}
Text before A label text after.

These declarations do not make this inline text label a 300 × 100px box.

Normal inline text elements do not use width and height like block elements do.

This example uses a text span. Images and other replaced inline elements have different sizing behaviour.

Check the common display traps

“Block means width: 100%.”
200px block

Automatic block width usually uses the available space. An explicit width can make it narrower.

“Inline content can never wrap.”
Text can continue onto another line when space runs out.

Inline content participates in text lines, including wrapping.

“Width and height work the same on every inline element.”
Text label

This normal inline text span does not become 300 × 100px. Inline-block allows that kind of sizing.

“Inline-block always starts a new line.”
One
Two
Three

It participates inline. A new line is needed when there is not enough room.

“A div is always block; a span is always inline.”

Those are defaults. CSS can change display, as the price example shows.

“Change the HTML tag whenever the layout looks wrong.”

Choose HTML for meaning and structure. Change CSS for presentation and layout behaviour.

“display: none just makes an element transparent.”

It removes the element from displayed layout. Neighbours can use its former space.

CSS Display

Explain and apply display behaviour

Explain your reasoning before revealing the guide. Drafts save in this browser.

1. Compare block and inline

Explain one difference between display: block and display: inline. Refer to what happens to neighbouring content.

Show answer guide

A block normally starts a new line; inline content joins the surrounding line and can wrap. Normal blocks accept width/height sizing; normal inline text elements do not in the same way.

2. Keep the link; change the layout

A navigation link should remain a link, be 120px wide and sit beside other links when space allows. Write a rule using the class menu-link.

Show answer guide

.menu-link { display: inline-block; width: 120px; } It keeps its link meaning while joining a line as a sized box.

3. Debug a text label

A span uses .label { display: inline; width: 200px; }. Explain why it may not be 200px wide and suggest a change that keeps it alongside other content.

Show answer guide

Normal inline text elements do not use width like block boxes. Change display to inline-block so the width can apply while the label participates inline.

4. Explain semantics

A span with class price changes to .price { display: block; }. Explain what changes and what stays the same.

Show answer guide

The span now starts a new line in normal flow. It remains a span in the HTML: its element type and meaning are not changed by the display declaration.

Glossary

Display vocabulary

Normal flow
The predictable sequence content follows without special layout rules.
Display
How an element participates in layout.
Wrapping
Content moving onto another line when horizontal space runs out.
Semantics
The meaning and structure expressed by the HTML.
Default behaviour
The starting behaviour an element commonly has before CSS changes it.
