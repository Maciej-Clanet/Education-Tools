Images, alt text, and useful page sections

Images make a page more useful, but they need clear HTML. In this lesson, you will add images, write helpful alt text, and use common sectioning tags to organise page content.

Quick Recap

Tags tell the browser what each piece of content is

You have already used tags for paragraphs, headings, links, and lists. Some tags wrap text between an opening and closing tag. Some tags use attributes to point to another resource.

<p>Text</p> Wrapped text

Paragraphs and headings wrap the content they describe.

<a href="..."> Attributes

Links use href to point to another page or section.

<ul> <li> Nested structure

List items only make proper sense inside a list container.

The Img Tag

The image tag embeds an image into the page

The <img> tag is different from paragraph or heading tags. It does not wrap text. It points to an image file and asks the browser to display that file.

<img> No closing tag

Img is a void element, so it does not use </img>.

src="..." The source attribute

The image content comes from the file named in the src attribute.

alt="..." Alternative text

Alt text describes the image when the image cannot be seen.

A basic image element

The tag has attributes, but no text inside it. There is nothing for a closing tag to wrap.

Alt Text

Alt text explains an image when the image is not available

Alt text is used by screen readers, search tools, and browsers when an image does not load. It should describe the useful information the image adds to the page.

alt="Raised beds..." Useful alt text

Describe the important content or purpose of the image.

alt="image" Too vague

Words like "image" or "photo" do not explain what is shown.

alt="" Decorative images

Empty alt can be used when an image adds no useful meaning.

Loaded image, then broken image

The same alt text can still communicate the image meaning when the image file cannot be loaded.

Useful Sections

Some tags organise whole parts of a page

You already know that <div> can group content without adding meaning. Sectioning tags also group content, but they describe the role or theme of that group.

<div> Generic group

A div is useful for layout or styling when no meaningful HTML tag fits.

<section> Themed group

A section groups related content that has a clear theme, usually with its own heading.

<section> A themed part of a page

Useful for content such as gallery, timetable, or contact sections.

<article> Self-contained content

Useful for a post, news item, review, or update that could stand alone.

<nav> Important navigation links

Useful for menus or major links around the page or website.

<figure> Media with a caption

Groups an image, diagram, or code example with a visible caption.

Images inside useful page sections

The image still needs alt text. The figure caption is visible on the page, while the alt text supports the image itself.

Glossary

Quick glossary

Img
A void element that embeds an image file into the page.
Src
The attribute that points to the image file.
Alt text
Text that describes an image when the image cannot be seen.
Section
A meaningful group of related content, usually with a heading.
Figure
A group for media such as an image, often with a caption.

Remember

Images need meaning

  • Img is a void element, so it has no closing tag.
  • Src points to the file the browser should load.
  • Alt text explains the image if it cannot be seen.
  • Use sectioning tags when the group has meaning.
