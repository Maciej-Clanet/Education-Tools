HTML document structure

Most HTML pages use the same core document shape: a document type, an <html> element, a <head> for page information, and a <body> for visible content.

Quick Recap

The document has a few jobs before content appears

The first HTML lesson introduced these parts. This lesson looks at how they fit together and how they help the browser understand a complete page.

<!doctype html> Use modern HTML

Tells the browser to read the page as modern HTML.

<html> Wrap the document

Contains the head and body for the whole page.

<head> Describe the page

Stores metadata, titles, and linked resources.

<body> Show the content

Contains the visible page content people use.

Document Skeleton

A full HTML page has an outer structure

The doctype is not an element, but it belongs at the top. After that, the <html> element wraps the two big areas: <head> and <body>.

1. Doctype Browser instruction: use modern HTML.
2. HTML element The outer container for the page.
3. Head element Information about the page, not the visible article.
4. Body element The visible page content.

<header> The header introduces an area

On a whole page, it often contains a site title, logo, search, or navigation. Inside an article, it can introduce that article.

<nav> Navigation often lives nearby

A header often contains a nav element, but the nav can also be elsewhere if that makes the page clearer.

<main> Main marks the unique content

It should contain the central content of that page. A page normally has one main element.

<aside> Related content can sit beside it

Side notes, related links, or supporting panels can be separate from the main story.

<footer> The footer closes or supports an area

On a page, it might hold copyright, contact links, or update notes. In an article, it might hold author details or tags.

<article> Sections can have their own structure

Header and footer are not only top and bottom of the entire website. They can describe smaller pieces of content too.

Glossary

Quick glossary

Doctype
The instruction that tells the browser to use modern HTML.
Head
Page information such as metadata, title, and linked resources.
Body
The part of the document containing visible content.
Semantic element
An element whose name describes the meaning of its content.
Div
A generic grouping element with no built-in semantic meaning.

Remember

Structure before style

  • The skeleton gives the browser the outer page shape.
  • Header, main, and footer describe common content areas.
  • Semantic elements describe meaning, not automatic design.
  • Use a div when you need a group but no meaningful tag fits.
