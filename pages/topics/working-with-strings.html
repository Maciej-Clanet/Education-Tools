Strings Recap

Strings are text values

const firstName = "Alex";
const surname = "Smith";
New problem

What if we want to combine several pieces of text into one message?

Joining Text

The + symbol can join strings together

const name = "Alex";

console.log("Hello " + name);
"Hello "+name→Hello Alex
Concatenation

Joining strings together.

The + symbol can also be used for calculations. We will cover that properly in the next lesson.

Exact Joining

JavaScript does not automatically add a space

Code 
firstName + surname
Output AlexSmith

What is missing?

JavaScript joins exactly what we tell it to join.

Add a one-character string containing a space

firstName+" "+surname

" " may look blank, but it is a string containing one space character.

A Longer Greeting

Concatenation still works when input changes the values

const firstName = prompt("What is your first name?");
const surname = prompt("What is your surname?");

console.log(
  "Hello " + firstName + " " + surname + ", welcome to the website!"
);
"Hello "+firstName+" "+surname+", welcome..."

This works. With several values, however, all the quotation marks and + symbols can make the code harder to read.

A Different Character

A backtick is not an ordinary quotation mark

Double quote"
Single quote / apostrophe'
Backtick`

Usually found here on a UK keyboard

Esc
¬` 1! 2" 3£

On many UK keyboards, the backtick key is immediately to the left of 1, below or near Esc, and often shares a key with ¬. Keyboard layouts vary.

Template Literals

Text surrounded by backticks is a template literal

`Hello`

A template literal can include ordinary text and places where JavaScript inserts values.

`Hello ${name}!`

Backticks surround the complete template literal.

${name} means: insert the value of name here.

${...} lets JavaScript insert a value or expression into a template literal. We will keep the contents simple in this lesson.

Same Result, Two Approaches

Both can work; one is often easier to read

Concatenation with + 
"Hello " + firstName + " " + surname +
", welcome to the website!"

Useful for simple joining.

Template literal 
`Hello ${firstName} ${surname},
welcome to the website!`

Often clearer when several values are inserted.

Common Mistake

Ordinary quotation marks do not insert ${...}

Ordinary quotes 
"Hello ${name}"
Output: Hello ${name}
Backticks 
`Hello ${name}`
Output: Hello Alex

${...} interpolation only works inside a template literal that uses backticks.

Explain · 3 marks

Why might a template literal be clearer than concatenation for a long profile message?

Show answer guidance

A strong answer explains that concatenation can need many quotation marks and + symbols. A template literal keeps the message together and marks each inserted value with ${...}, which can make a longer message easier to read. Both approaches can work.

Glossary

Quick glossary

String
A text value.
Concatenation
Joining strings together.
Backtick
The ` character used around a template literal.
Template literal
Text surrounded by backticks that can include inserted values.
Interpolation
Inserting a value or expression into a template literal with ${...}.

Remember

The readable pattern

  • Backticks surround the message.
  • ${...} marks each insertion.
  • Write spaces and punctuation where they should appear.
  • Ordinary quotes do not interpolate.
