Quick Recap

An image cannot contain a child, but a link can contain an image

You already know that <img> is a void element. It gets its image from the src attribute and cannot have content nested inside it.

Void element 
<img src="cat.jpg"
  alt="A black cat">

<img> cannot contain text or another element.

Parent with one child 
<a href="cats.html">
  <img src="cat.jpg"
    alt="A black cat">
</a>

The link contains the image, so the image becomes clickable.

A link is not limited to text

An anchor can contain suitable content such as an image. Here, <a> is the parent and <img> is its child.

Nesting

Nesting means placing one HTML element inside another

You have already placed list items inside a list. A nested list adds another level inside one of those list items. Indentation makes each level visible, while the tags create the real structure.

Indented HTML

<ul>
  <li>Dogs</li>
  <li>
    Cats
    <ul>
      <li>Black cats</li>
      <li>Orange cats</li>
    </ul>
  </li>
</ul>

The same structure as a tree

liDogs
liCats
ulinner list
liBlack cats
liOrange cats

Text version: the outer ul contains two li elements. The second li also contains another ul, which contains two more li elements.

Relationship Words

Parent, child, sibling, and descendant describe where elements sit

These words describe relationships, not permanent types of element. The same element can have several relationships at once.

Parent

Contains another element as part of its content.

Direct child

Sits exactly one level inside a parent.

Sibling

Shares the same direct parent with another element.

Descendant

Sits anywhere deeper inside an element, even several levels down.

header · parent
img · child
nav · child and parent

A child can also be a parent

<nav> is a child of <header>, a sibling of <img>, and the parent of three links—all at the same time.

Nesting can keep going through deeper levels. The relationship depends on which two elements you compare.

One-level test:

The outer <ul> has the two outer <li> elements as direct children. The inner <ul> is a descendant, but not a direct child, because another <li> sits between them.

Moving Together

When a parent moves, its contents move with it

Move the second parent using the control. Its heading, paragraph, and button keep their positions inside it because they are part of that parent's contents.

CSS is moving the parent behind the scenes. You do not need the CSS yet—the important idea is that nested content travels with its container.

Grouping Content

Div creates a generic group when no meaningful element fits

A <div> can group several children into one container. The whole card can later be moved or styled as one unit.

A grouped animal card

The div is the direct parent of the image, heading, paragraph, and link.

Use a meaningful element when it fits

Navigation should usually use <nav>. Self-contained content may suit <article>.

Use div for a generic container

Choose <div> when the group needs a container but has no clearer semantic meaning.

Readable and Correct

Indent for people, then close from the inside out

Tags create relationships; spaces do not. Indentation is still essential because it lets a person see the levels and spot mistakes quickly.

Hard to scan

<header><nav><a href="#">Home</a><a href="#">About</a></nav></header>

The browser can read it, but the levels are hidden from the person editing it.

Structure visible

<header>
  <nav>
    <a href="#">Home</a>
    <a href="#">About</a>
  </nav>
</header>

Each level steps inward, and matching opening and closing tags line up.

Common Traps and Practice

Explain the structure, then repair it

Every child is not a direct child

A descendant can be several levels down. Count one level only when asked for direct children.

Indentation does not fix tags

Neat spacing helps you see structure, but only correctly placed opening and closing tags create it.

Div is not the automatic answer

Use a semantic element when its meaning fits; use div for a genuinely generic group.

Glossary

Quick glossary

Nesting
Placing an element inside another element.
Parent
An element that directly contains another element.
Direct child
An element exactly one level inside its parent.
Sibling
An element that shares the same parent.
Descendant
An element anywhere deeper inside another element.
Div
A generic container with no extra semantic meaning.
