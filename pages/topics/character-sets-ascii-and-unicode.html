Overview

Text is stored as numbers, then interpreted as characters

A computer does not store the shape of a letter every time you type it. It stores a numeric code. Software then uses an agreed character set to interpret that code as a letter, digit, symbol, or control instruction.

Foundations

A character set gives each character an agreed code

A character set is a standard mapping between stored numbers and characters. It can include letters, digits, punctuation, symbols, and control characters. If two systems do not agree on the mapping, the same stored data can be displayed incorrectly.

ASCII

ASCII is small, simple, and historically important

Standard ASCII uses 7 bits, giving 128 possible codes. It covers English uppercase and lowercase letters, digits, punctuation, and control characters. It is useful for explaining the principle of text encoding, but it is too limited for modern international text.

Space 32 0100000
0 48 0110000
A 65 1000001
a 97 1100001

Strength

ASCII is compact and easy to process for basic text.

Limit

Standard ASCII cannot represent characters such as £, é, or Ω.

Exam note

Extended ASCII exists, but different extensions used different extra characters, so compatibility was not guaranteed.

Unicode

Unicode is designed for many languages and symbols

Unicode gives characters from many writing systems a consistent code point. This helps websites, documents, databases, and messaging apps exchange text across countries, devices, and software platforms.

CJK character

Unicode is the character set, UTF-8 is an encoding

Unicode defines the code points. UTF-8 is one common way to store those code points as bytes. UTF-8 is widely used on the web because the first 128 Unicode code points match ASCII, while wider characters can use more bytes when needed.

Implications

Encoding choices affect compatibility, storage, and users

Text encoding is not just a technical detail. It affects whether users can type their names correctly, whether data is exchanged safely between systems, and how much storage or bandwidth text may need.

Issue Why it matters Example
Compatibility Systems must interpret the same bytes the same way. café can become cafÃ©.
Storage Wider characters can need more bytes in UTF-8. Plain ASCII text is compact.
Accessibility and inclusion People need names, languages, and symbols represented correctly. Unicode supports a wider range of writing systems.
Validation Systems should not reject valid characters unnecessarily. A form should handle accents and currency signs where needed.

Exam Traps

Common mistakes with text representation

Calling ASCII a language

ASCII is a character coding standard, not a spoken or written language.

Fix: Describe it as a character set or encoding standard.

Mixing up character set and font

A character set decides which code means which character. A font decides how that character looks on screen.

Fix: Use font only when discussing visual style.

Assuming Unicode always wastes storage

UTF-8 stores standard ASCII characters in one byte each, while wider characters use more bytes.

Fix: Say the storage impact depends on the encoding and characters used.

4 marks Explain

Question 1

Explain why computers need character sets instead of storing letters directly as visible symbols.

Show answer guide
  • Computers store data as binary values.
  • A character needs an agreed numeric code so it can be stored and transmitted.
  • Software uses the character set or encoding to interpret the code.
  • Without a shared standard, text could display as the wrong character.
6 marks Compare and justify

Question 2

Compare ASCII and Unicode for an international messaging app, then justify which standard is more suitable.

Show answer guide
  • ASCII has a small character range.
  • Unicode supports far more languages, scripts, and symbols.
  • Unicode or encodings such as UTF-8 can use more storage for wider characters.
  • An international messaging app needs broad language support, so Unicode is the stronger justified choice.

Remember

Same code, same meaning

  • Character sets let systems interpret text consistently.
  • ASCII is compact but limited to 128 standard codes.
  • Unicode is stronger for global modern computing.
  • Encoding mismatches can create garbled text.
