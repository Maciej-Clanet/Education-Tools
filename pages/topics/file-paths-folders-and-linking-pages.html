File paths, folders, and linking pages

A path tells the browser where to find another file. Use that one idea to find images, link pages, and debug the mistakes that make website files disappear.

Quick Recap

The value inside src is a path

You already know that <img> uses src to choose an image file. This lesson focuses on the text inside src and href.

src="images/panda.jpg" Find an image

The browser reads the path and tries to load that file.

href="pages/contact.html" Link to a page

The anchor uses the same path idea to move to another HTML file.

Main idea

A path tells the browser where to find another file.

Start with the src value

The tag is familiar. The new question is: where does that path send the browser?

Code

What it means

External Files

A path can point to another website

A complete address such as https://example.com/images/cat.jpg tells the browser to go somewhere else on the web and ask for that file.

https://example.com/images/cat.jpg Useful for quick demos

You do not need to keep the file inside your own project while testing an idea.

images/panda.jpg Useful for your own project files

The image belongs with the website files, so the project can move as a folder.

The trade-off

A file from another website can be changed, removed, blocked, or unavailable. You also need permission to use images appropriately.

Website Project

A website project is a folder full of files

HTML pages are files. Images are files. Folders help organise those files so paths are easier to read.

Animal-site project

animal-site/

|-- images/

Names are choices

Folders such as images/ or assets/ are common, but they are not magic HTML keywords. They are useful names chosen by the person making the project.

Use one clear project structure and make your paths match it.

Read the tree from the top folder downward

pages/contact.html means: inside animal-site, go into pages, then find contact.html.

Relative Paths

A relative path starts from the current file

Before writing a path, ask the same question every time: where am I starting from?

Current file

index.html

Start beside the home page in the main project folder.

Target file

images/panda.jpg

Go into images, then find panda.jpg.

Result: images/panda.jpg

    Using ../

    ../ means go up one folder level

    If the current file is inside pages/, the browser starts inside pages/. To reach a file outside that folder, the path must go up first.

    Current file

    pages/pandas.html

    Start inside the pages folder.

    Target file

    images/panda.jpg

    The image is not inside pages. It is in images.

    Directions:

    Go up/out of pages, go into images, find panda.jpg.

    ../images/panda.jpg

    Going up and then into another folder

    Current: pages/pandas.html
Target:  images/logo.png

Path:    ../images/logo.png

    The first part, ../, returns to the main project folder. The next part, images/logo.png, goes into the images folder and finds the file.

    Path Problems

    Some paths look believable but send the browser to the wrong place

    Debug paths logically. Do not guess. Ask: where am I starting from, and where would this path make the browser look?

    Absolute URL

    https://example.com/images/cat.jpg

    A complete web address. It points somewhere on the web.

    Relative path

    ../images/panda.jpg

    Directions from the current file inside this project.

    One computer

    C:\Users\Jamie\Pictures\panda.jpg

    This tells the browser where the file exists on Jamie's computer.

    The website project

    animal-site/
|-- index.html
`-- images/
    `-- panda.jpg

    The project path should describe where the file exists inside the website folder.

    Slash direction

    images/panda.jpg images\panda.jpg

    Website paths normally use /, not the Windows backslash.

    Filename and case

    Actual file: images/panda.jpg
HTML path:   images/Panda.jpg

    Capitalisation can matter when the website moves. Simple predictable filenames reduce mistakes.

    Debug and Practise

    Wrong paths can be traced too

    When a path fails, trace where it would actually go. That usually reveals the fix.

    Forgot the folder

    Current: index.html
Target:  images/panda.jpg

    Started inside pages

    Current: pages/pandas.html
Target:  images/panda.jpg
Wrong:   images/panda.jpg

      Linking Pages

      href uses the same path rules as src

      src can use a path to find an image. href can use a path to find another HTML page. The browser still starts from the current file.

      Navigation paths change depending on the current page

      Route

      What index.html usually means

      index.html is the conventional name for the main or home page of a website or folder. You will see and use that filename often.

      You will also see paths starting with /

      /images/logo.png

      Starting with / means start from the root of the website. You do not need to master this yet; most practice in this lesson uses normal relative paths.

      Glossary

      Quick glossary

      Path
      Directions or an address that tells the browser where to find a file.
      Relative path
      A path that starts from the current file.
      Absolute URL
      A complete web address such as https://example.com/image.jpg.
      ../
      Go up/out of the current folder once.
      index.html
      The common filename for a website or folder's main page.

      Remember

      Where am I starting from?

      • Paths start from the current file.
      • ../ goes up one folder.
      • Use / in website paths.
      • href and src use the same path logic.
