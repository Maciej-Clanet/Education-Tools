Quick Recap

Tags, attributes, and semantic tags all give HTML meaning

A tag tells the browser what kind of element to create. Attributes add extra information to a tag. Semantic tags describe what the content means, not just how it looks.

<a href="guide.html" > Read the guide </a>
<p> Tag

The tag name tells the browser what kind of element this is.

href="guide.html" Attribute

An attribute gives extra information, such as where a link goes.

<header> Semantic tag

The tag name describes the role or meaning of the content.

Paragraphs

The paragraph tag marks a block of normal text

Use <p> for a paragraph of text. Browsers give paragraphs default space above and below, so several paragraphs have a visible gap even before you write CSS.

Paragraphs have default spacing

The gap is not an empty line in your code. It is the browser's default paragraph margin.

A new line in your editor is not always a new line on the page

HTML collapses normal spaces and line breaks inside a paragraph. Use separate paragraphs for separate ideas, and use <br> only when the line break is part of the content.

Headings

Heading numbers describe structure, not just size

Browsers usually make <h1> bigger than <h2>, but that is only default styling. The numbers tell assistive technology and search engines how the page is organised.

<h1> School Garden Project The main page heading.
<h2> Why we are building it A major section under the page heading.
<h2> What we need Another major section at the same level.
<h3> Tools and materials A smaller subsection inside "What we need".

You can use the same heading level more than once

Two <h2> elements can be sibling sections. The number is a level in the outline, not a one-time label.

Common mistake

Do not invent paragraph numbers. There is no <p1> or <p2> for paragraph importance. 

<p1>Most important paragraph</p1>
<p2>Less important paragraph</p2>
Use paragraphs for paragraphs

Paragraphs are all the same kind of element. Use headings to organise sections, then use normal <p> tags for the text underneath. 

<h2>Important update</h2>
<p>This paragraph explains the update.</p>
<p>This paragraph adds another detail.</p>

Links

The anchor tag needs an href to become a useful link

The <a> tag creates an anchor. The href attribute tells the browser where the link should go.

No href, then href

Without href, the text is not a real link. Once the href is added, the browser gives it default link styling and it can be opened.

target="_self" Default behaviour

If you do not add a target, the browser usually opens the link in the same tab.

target="_blank" New tab

This asks the browser to open the link in a new tab or window. Use it when leaving the current task would be disruptive.

Opening a link in a new tab

The destination is still in href. The target changes where the browser opens it.

Links can also jump to part of the same page

A value like #plan points to an element with id="plan". For now, think of an id as a unique label on part of the page.

Lists

List item tags work inside list containers

The <li> tag means list item. It belongs inside an unordered list <ul> or an ordered list <ol>. The container changes how the items are presented.

The list container changes the list item

The same <li> tags become bullet points in a <ul> and numbered steps in an <ol>.

Lists can be nested inside other lists

There is no tiny built-in limit to how deep nesting can go, but deeply nested lists are hard to read. Closing tags clearly matters more as the structure gets deeper.

Build a small information page

Use the tags from this lesson to make a small page about a school club, local event, game guide, recipe, or project idea.

Include these HTML features
  1. One h1 for the page title.
  2. At least two h2 headings for major sections.
  3. At least three paragraphs of normal text.
  4. One link with an href attribute.
  5. One ul or ol with at least three li items.

Glossary

Quick glossary

Paragraph
A block of normal text marked with a p element.
Line break
A forced new line inside content, often made with br.
Heading
A title or section label that helps organise the page outline.
Hyperlink
A link to another page, file, website, or part of the same page.
List item
An li element that belongs inside a ul or ol list.
Nesting
Putting one element inside another element.

Remember

Meaning first

  • Paragraphs are for normal text blocks.
  • Heading numbers describe the page outline.
  • Links need href to go somewhere.
  • List items belong inside ul or ol.
