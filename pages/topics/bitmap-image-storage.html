More values make smoother tones

Keep the pixel positions fixed. Change only how many shades each pixel can represent.

Banding means visible jumps between tones. More available shades can make those jumps smaller without adding pixels.

Not every image is stored as a grid of pixels

A vector image stores descriptions of shapes: their positions, sizes, fills and outlines.

Image storage

Vectors have limits too

The representation should match the content and how the finished image will be used.

Photographs need many local variations

A pixel grid is usually a practical way to store natural texture, lighting and colour. Describing that detail with shapes can become very complicated.

Complexity adds data and work

More objects, paths and control points need more data and rendering work. Complex vector artwork may be larger than a raster version.

Check the required output format: an SVG can contain vector and raster content. Exporting a vector to PNG produces a raster image with fixed pixel dimensions.

Image storage

Explain the effect, not just the label

Use what is stored to explain what changes and what stays the same.

Does higher bit depth add more pixels?

No. It gives each existing pixel more possible values. Increasing dimensions adds more pixel positions.

Does making a bitmap larger recover missing detail?

No. Existing samples can be spread out or interpolated, but the original details that were not captured cannot be recovered by ordinary enlargement.

Is vector always the smallest or best choice?

No. Simple shapes can be compact and easy to edit, but photographs usually suit raster data and complex vectors can contain many objects and points.

Apply the ideas in writing

Write first, then compare with the answer guidance. Drafts save automatically in this browser.

4 marksPractice 1

Explain bitmap storage and bit depth

Explain how a bitmap stores a photograph. Describe one effect of increasing its bit depth while keeping its dimensions fixed.

Show answer guide
  • A bitmap stores a grid of pixel values, with dimensions identifying the rows and columns.
  • Each position has a stored value describing its colour or selecting a palette entry.
  • Greater bit depth provides more possible values for each pixel, allowing finer colour or tonal steps.
  • It uses more uncompressed pixel data for the same number of positions; it does not add more pixels.
4 marksPractice 2

Calculate and explain the pixel data

A small image is 12 pixels wide and 8 pixels high. It uses 2 bits per pixel. Calculate its uncompressed pixel-data size in bytes, then explain why this might differ from its saved file size.

Show answer guide
  • 12 × 8 = 96 pixels.
  • 96 × 2 = 192 bits.
  • 192 ÷ 8 = 24 bytes of uncompressed pixel data.
  • The saved file may also contain headers, palette data or padding, and compression may change its size.
6 marksPractice 3

Recommend representations for a project

A museum needs a detailed photograph of an artefact and a simple venue logo used on tickets and a large sign. Recommend a representation for each and explain a relevant limitation of your choices.

Show answer guide
  • Raster suits the many local colour and tonal variations in the photograph.
  • Its source needs enough pixels for the intended display; enlargement cannot restore missing detail.
  • Vector suits a simple logo described by shapes and lines that can be rendered at ticket and sign sizes.
  • Individual objects can be edited separately in a vector editor.
  • Simple vectors can be compact, but complex artwork is not guaranteed to be smaller; check the required output format.

Glossary

Quick glossary

Bitmap
An image stored as a grid of pixels.
Vector
An image stored as drawing instructions for objects.
Pixel
One picture element in a bitmap image.
Raster
Another term for a pixel-grid image structure.
Bit depth
The number of bits allocated to one pixel in this lesson. More bits allow more possible pixel values.

Remember

Pixels or instructions?

  • Bitmaps store colour data for each pixel.
  • Vectors store shape and drawing instructions.
  • Photos usually suit bitmap storage.
  • Logos and diagrams often suit vector storage.
