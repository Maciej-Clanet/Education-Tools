Overview

Images can be stored as pixels or as instructions

Digital images are stored as binary data, but not all image files describe pictures in the same way. Bitmap images store a grid of pixels. Vector images store instructions for shapes, lines, text, colours, and positions.

Bitmap

Stores colour data for each pixel in a raster grid.

Vector

Stores mathematical drawing instructions for objects.

Learning goals

Quick memory hooks

  • Bitmap: pixel-by-pixel storage.
  • Vector: shape-by-shape instructions.
  • Photos: usually bitmap.
  • Logos: often vector.

Two Models

Bitmap and vector files answer different questions

A bitmap asks: what colour is the pixel at each position? A vector asks: what shapes should be drawn, with which sizes, positions, fills, and strokes?

Bitmap data

row 1: #1f877d, #1f877d, #ffffff
row 2: #b98c19, #ffffff, #253442

More pixels means more stored colour entries.

Vector data

circle cx=40 cy=40 r=20
line x1=10 y1=80 x2=90 y2=15

More objects means more drawing commands.

Bitmap Pixels

Bitmap images are built from rows and columns of pixels

A bitmap stores a rectangular grid. Each position in the grid is a pixel, and each pixel stores colour information. When many pixels are shown together, the full picture appears.

Colour

Each bitmap pixel needs data to describe its colour

A simple black-and-white bitmap could use 1 bit per pixel. A colour image needs more bits per pixel so each pixel can represent more possible colours. This is why bit depth affects storage.

1 bit per pixel 2 possible colours
8 bits per pixel 256 possible colours
24 bits per pixel Over 16 million possible colours

Bitmap Storage

Bitmap file size grows with pixels and bits per pixel

Raw bitmap data can be estimated by multiplying width by height by bits per pixel. Extra metadata and compression can change the final file size, but the basic storage pressure comes from pixel count and colour depth.

Raw bitmap size in bits width x height x bits per pixel

Example: 100 x 100 x 8 = 80,000 bits before extra file data or compression.

Vector Images

Vector images store objects and instructions

A vector image stores data such as shape type, coordinates, radius, line thickness, fill colour, and text. The image is drawn from those instructions when displayed.

Scales cleanly

A circle instruction can be redrawn at many sizes without becoming pixelated.

Great for graphics

Logos, diagrams, icons, charts, and simple illustrations are strong vector use cases.

Not ideal for photos

A photograph contains complex colour variation, so pixel-based bitmap storage is usually more suitable.

Choosing

Choose the format by image content and use

Feature Bitmap Vector
Stored as Pixels in rows and columns Shapes, coordinates, colours, and drawing commands
Best for Photos and complex colour detail Logos, icons, diagrams, and simple graphics
Scaling Can become blocky when enlarged Can redraw cleanly at different sizes
Storage pressure More pixels and colour depth increase size More objects and detail increase instruction data

Exam Traps

Common mistakes with image storage

Using bitmap and vector as if they are the same

Bitmap images store pixel data. Vector images store drawing instructions.

Fix: Start answers by naming what is stored.

Saying vectors never use much storage

Simple vectors can be compact, but very complex vector artwork can still contain lots of data.

Fix: Link vector size to number and complexity of objects.

Forgetting why photos are usually bitmap

Photographs have detailed colour variation that is naturally stored pixel by pixel.

Fix: Use vector for logos and diagrams, not as a default answer for every image.

4 marks Explain

Question 1

Explain how a bitmap image stores a photograph and why that storage method can use a large amount of data.

Show answer guide
  • A bitmap stores the image as a grid of pixels.
  • Each pixel stores colour information.
  • Large images contain many pixels, each needing data.
  • Higher colour detail or bit depth can increase the amount of data further.
6 marks Compare and justify

Question 2

A school needs a website logo that will appear as a small icon and on a large banner. Compare bitmap and vector storage for this task, then justify a suitable choice.

Show answer guide
  • A bitmap stores pixels and may become blocky when enlarged.
  • A vector stores shapes and coordinates, so it can be redrawn at different sizes.
  • Logos usually contain simple shapes and text rather than photographic colour detail.
  • Vector is therefore a suitable choice for a scalable logo.

Glossary

Quick glossary

Bitmap
An image stored as a grid of pixels.
Vector
An image stored as drawing instructions for objects.
Pixel
One picture element in a bitmap image.
Raster
Another term for a pixel-grid image structure.
Bit depth
The number of bits used to store each pixel's colour.

Remember

Pixels or instructions?

  • Bitmaps store colour data for each pixel.
  • Vectors store shape and drawing instructions.
  • Photos usually suit bitmap storage.
  • Logos and diagrams often suit vector storage.
