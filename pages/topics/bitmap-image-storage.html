Why must a decoder know the image dimensions?

Dimensions tell it how many pixel positions belong in each row and how many rows form the image. The bit sequence alone does not specify the intended shape.

Representations and file formats

PNG and JPEG are raster examples; our SVG badge contains vector shapes. SVG can also contain raster images. Renaming a file extension does not convert the stored representation.

Vector artwork is not always smaller: its size depends on the amount and complexity of its content. A detailed photograph usually maps more naturally to raster values.

Image storage

Use the mechanism to challenge the claim

Open each explanation after deciding whether the claim follows from what is stored.

“Painting every white square gold must increase the raw pixel data.”

Not in our fixed-width model: there are still 32 pixels and two bits per pixel. Values change; the 64-bit allocation does not. Compression could respond differently, which is a later topic.

“Zooming in creates the detail that the camera missed.”

Enlargement can spread or interpolate the available samples. It cannot recover the original details that were never captured.

“Vector files always use less storage.”

A short description of simple shapes can be compact. Many complicated objects and embedded content can require substantial data; the representation alone does not guarantee the smallest file.

  • The first row is white, teal, gold, ink.
  • Each two-bit code describes one pixel through the stated palette.
  • The whole image has 16 pixel positions, not 32 positions.
4 marksPractice 2

Explain how the picture is reconstructed

Explain why pixel codes alone may not be enough to reconstruct the intended bitmap photograph.

Show answer guide
  • A bitmap has ordered pixel values arranged in rows and columns.
  • The width and height identify the intended grid and row boundaries.
  • The decoder needs the pixel format or bit depth to separate and interpret values.
  • For indexed colour it also needs the palette mapping codes to colours; direct-colour images use their stated colour format.
4 marksPractice 3

Calculate the pixel data

A small image is 12 pixels wide and 8 pixels high. It uses 2 bits per pixel. Calculate its uncompressed pixel-data size in bytes, then explain whether this must equal its saved file size.

Show answer guide
  • 12 × 8 = 96 pixels.
  • 96 × 2 = 192 bits.
  • 192 ÷ 8 = 24 bytes of uncompressed pixel data.
  • The saved file may also contain headers, palette data or padding, and compression may change its size.
6 marksPractice 4

Recommend two representations

A museum needs a detailed photograph of an artefact and a simple venue logo used on tickets and a large sign. Recommend a representation for each image and justify your decisions.

Show answer guide
  • Raster suits the many local colour variations in the photograph.
  • It must have enough source pixels for its intended display; enlarging it cannot recover missing original detail.
  • Vector suits a simple logo described by shapes and lines.
  • The geometry can be rendered at the ticket and sign sizes.
  • Do not claim that vectors always use less storage or that raster images cannot contain logos.

Glossary

Quick glossary

Bitmap
An image stored as a grid of pixels.
Vector
An image stored as drawing instructions for objects.
Pixel
One picture element in a bitmap image.
Raster
Another term for a pixel-grid image structure.
Bit depth
The number of bits per pixel in this lesson's model; colour-channel depth is introduced next.

Remember

Pixels or instructions?

  • Bitmaps store colour data for each pixel.
  • Vectors store shape and drawing instructions.
  • Photos usually suit bitmap storage.
  • Logos and diagrams often suit vector storage.
