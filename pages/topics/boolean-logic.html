Boolean logic

Three Boolean operations

An input is a value given to an operation. The output is the result.

OperationDescription
ANDThe result is true only when both inputs are true.
ORThe result is true when one or both inputs are true.
NOTReverse one input: true becomes false, and false becomes true.

Other logic gates include XOR, NAND and NOR. This lesson uses AND, OR and NOT.

Boolean logic

Check these three common mistakes

OR includes both

1 OR 1 = 1. “At least one” includes two true inputs.

NOT applies to a specific part

A AND (NOT B) reverses B. NOT (A AND B) reverses the combined result.

Keep all input combinations

Two inputs need 4 rows. Three inputs need 8 rows. Working columns do not add rows.

Boolean logic

Explain the college entry decision

A = valid ID. B = current enrolment. C = blocked account.

Entry = (A AND B) AND (NOT C)

A student has a valid ID and current enrolment, but the account is blocked. Work through the rule. Explain what changes if the block is removed.

Your answer saves on this device.

Show answer guidance

Initially A = 1, B = 1, C = 1. A AND B gives 1, but NOT C gives 0. The final result is 1 AND 0 = 0, so entry is refused.

Removing the block changes C to 0. NOT C becomes 1. The final result becomes 1, so entry is allowed.

Glossary

Key terms

Boolean logic
A system of true or false decisions used in computing.
Operator
A logical rule such as AND, OR, or NOT.
Truth table
A table showing every possible input and output state.
Expression
A written logic rule that combines inputs and operators.

Remember

Conditions to outputs

  • AND means every condition must be true.
  • OR means at least one condition is true.
  • NOT flips the state before the output is decided.
