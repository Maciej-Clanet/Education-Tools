What if child 2 contains a span?

The span is a child of child 2. It is a grandchild of .parent, so it does not become a fourth item in the outer parent’s flex layout.

4. Name the two directions

The main axis follows the direction of the children. The cross axis goes across it, at a right angle.

Main follows the children. Cross goes across main.

Predict: in a column, which axis goes left to right?

The cross axis. The main axis now goes top to bottom.

Cross axis · align-items

  justify-content: center;
  align-items: flex-start;
}

Row: the group is centred left to right; each child stays at the top.

The properties follow their axes, even when the axes turn.

Why is the column on the left, halfway down?

justify-content: center centres the group on the now-vertical main axis. align-items: flex-start places each child at the left of the now-horizontal cross axis.

Check your language: say “main” and “cross” before saying “horizontal” or “vertical”.

9. Why do children sometimes stretch?

The default align-items value is stretch. These children now have automatic width and height. Compare stretch with center.

Main axis · justify-content
Cross axis · align-items
1
2
3
.parent {
  display: flex;
  flex-direction: row;
  align-items: stretch;
}

With automatic height, each child stretches across the vertical cross axis.

Stretch can fill the cross axis when the child’s cross size is automatic.

Earlier examples kept both dimensions at 48px. A fixed height prevents this row’s vertical stretching. A fixed width prevents a column’s horizontal stretching.

12. Is a gap the same as space-between?

The gap stays at 16px. First change justify-content. Then change the parent’s width.

Parent .parent · children 1, 2, 3

1
2
3
.parent {
  display: flex;
  justify-content: flex-start;
  gap: 16px;
}

The children are exactly 16px apart. A wider parent leaves more spare space after child 3.

Gap setting: 16px. Actual space between children: 16px.

gap sets the gap. space-between can add more space between the children.

On a narrow screen, both width choices may fit the same available space. Try this example in Teacher Slides or on a wider screen to compare widths.

13. Put the familiar pieces together

Try each recipe in order. Reset between recipes, and name the axis before choosing its property.

Parent .parent · children 1, 2, 3

Main axis · justify-content
Cross axis · align-items
1
2
3
.parent {
  display: flex;
  flex-direction: row;
  justify-content: flex-start;
  align-items: flex-start;
  gap: 0px;
}

Direction: row. Main is horizontal; cross is vertical. Gap: 0px.

Recipe 1: a row centred both ways, with 16px gaps

Keep row. Set justify-content: center, then align-items: center, then gap: 16px.

Recipe 2: a column centred left to right, starting at the top, with 8px gaps

Set column, keep justify-content: flex-start, set align-items: center, then gap: 8px. Left to right is the column’s cross axis.

Recipe 3: a row spread out, centred vertically

Use row, justify-content: space-between and align-items: center.

Flexbox basics

15. Catch the common mistakes

“I put display: flex on every child.”

Apply it to their shared parent to arrange those children. On a child, it would arrange that child’s own contents.

“Justify means horizontal; align means vertical.”

First check direction. Justify follows main; align follows cross. In a column, justify works vertically and align works horizontally.

“align-items: center did nothing.”

Check that the parent uses Flexbox, check the cross axis, then look for spare space on that axis.

Two spacing checks

“gap should add space at the outside edges.”

Gap is between neighbours. Padding creates space between a parent’s edge and its contents.

“space-between always means a 16px gap.”

It distributes available space. Use gap: 16px with justify-content: flex-start in these examples for a consistent 16px separation.

16. A small Flexbox reference

Parent → direction → main axis → cross axis → gap.

All of these declarations go on the parent.
PropertyJob
display: flexStart Flexbox for the direct children.
flex-directionChoose row or column; this defines the main axis.
justify-contentPosition or distribute children along main.
align-itemsAlign each child across main, on the cross axis.
gapAdd space between neighbouring children.

Explain and apply Flexbox

Write an answer before opening the guide. Drafts save in this browser. Use the mark points to check your reasoning.

1. Explain the two axes

A parent has display: flex; flex-direction: column;. Explain the direction of each axis and the job of align-items. (3 marks)

Show answer guide

One mark each: the main axis goes top to bottom; the cross axis goes left to right; align-items positions each child on the horizontal cross axis.

2. Write a centred row

Write a rule for .toolbar. Its children should form a row, the group should be centred horizontally, each child should be centred vertically, and neighbours should have a 16px gap. Include a parent height of 200px. (6 marks)

Show answer guide
.toolbar {
  display: flex;
  flex-direction: row;
  justify-content: center;
  align-items: center;
  gap: 16px;
  height: 200px;
}

One mark for each declaration. Row is the default, but writing it here makes the chosen direction clear.

3. Fix a column’s alignment

A column should keep its children at the top and centre each one left to right. A learner wrote:

.parent {
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: flex-start;
}

Correct the two alignment declarations and explain which axis each uses. Assume the parent has spare space in both directions. (4 marks)

Show answer guide
justify-content: flex-start;
align-items: center;

Two marks for the corrections. One for explaining that justify uses the vertical main axis, keeping the group at the top. One for explaining that align uses the horizontal cross axis, centring each child left to right.

4. Explain a changing gap

A row uses gap: 16px; justify-content: space-between;. The parent gets wider while the children keep their sizes. Explain why the visible spaces increase. How could you keep the children exactly 16px apart and leave spare room after them? (3 marks)

Show answer guide

One mark each: the wider parent has more spare main-axis space; space-between shares that extra space between children in addition to the gap; keep gap: 16px and use justify-content: flex-start.

Key terms

Parent
The element directly containing the children being arranged.
Child
An element directly inside its parent.
Flex container
The parent with display: flex.
Flex item
A direct child participating in the parent’s flex layout.
Main axis
The axis defined by flex-direction.
Cross axis
The axis at a right angle to the main axis.
Spare space
Room left inside the parent after the children and gaps have taken their space.
Gap
Space added between neighbouring children.
Stretch
Cross-axis alignment that can expand a child with an automatic cross size.
