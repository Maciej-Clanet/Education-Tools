Could bits describe a pixel?

In a simple 8-bit greyscale representation:

00000000 → black 11111111 → white

Audio samples and control values also use agreed rules.

Binary becomes useful data when the computer knows how the bits should be interpreted.

Binary and BCD

Why computers use binary

0 LOW / OFF-like state
1 HIGH / ON-like state

Electronic systems can reliably distinguish between two states.

Combining many bits creates many possible patterns. Agreed rules let those patterns represent numbers, text, images, instructions and other data.

These are logical states; a physical bit need not be a literal light switch.

Binary and BCD

Denary and binary: what changes?

Denary · base 10

Digits 0–9 · places grow by ×10 to the left.

100 5 10 4 1 3

543 = 5 hundreds + 4 tens + 3 ones.

Binary · base 2

Digits 0 and 1 · places grow by ×2 to the left.

4 1 2 0 1 1

101 = 1 four + 0 twos + 1 one = 5 in denary.

A digit’s position determines its value.

Why keep decimal digits separate?

2 7

What if the system wants to store each displayed decimal digit separately?

Encode each digit
2 ↓ 0010 one decimal digit
7 ↓ 0111 one decimal digit

27 → 0010 0111

Binary Coded Decimal (BCD) stores each decimal digit separately using a 4-bit binary code.

Keep the decimal digits in order. Give each digit its own group of four bits, including leading zeros.

6 → 0110

8 → 1000
9 → 1001
What about the other six patterns?

1010 1011 1100 1101 1110 1111

Not valid single decimal digits in standard BCD. A decimal digit can only be 0–9.

Within each 4-bit group, use the values 8, 4, 2, 1.

Pure binary · one whole number

27 → 00011011

16 + 8 + 2 + 1 = 27

BCD · separate decimal digits

2 ↓ 0010 one decimal digit

Same displayed value, different bit pattern.

The meaning depends on the representation rule, just as it did with our opening bit pattern.

Binary and BCD

BCD can connect codes to decimal displays

A device needs to display 42 . Each digit has its own BCD code and display position.

0100 ↓ digit decoder 4
0010 ↓ digit decoder 2

BCD is useful where decimal digits need to remain separate or map conveniently to a decimal display.

A real component example

A BCD-to-seven-segment display decoder can turn a digit’s BCD code into signals for a display. Such components can be used in instruments and control equipment.

This does not mean all displays, calculators or computers store their numbers as BCD.

Reveal the BCD interpretation
0010 ↓ 2

Do not treat the entire BCD bit string as one ordinary binary number.

Spaces help show the groups. The BCD rule—not the spaces—gives each group the meaning of one decimal digit.

Common mistakes

Spot the misconception

“Binary is only used for numbers.”

False. A bit pattern can represent many kinds of data. Its meaning depends on the interpretation rule.

“A 1 means the decimal value 1.”

Not necessarily. It means its place-value column is active: a 1 in the 128 column contributes 128.

“The two conversion directions use completely different systems.”

False. Both use 128, 64, 32, 16, 8, 4, 2, 1. One adds active values; the other chooses which values to include.

“BCD is just normal binary with spaces.”

False. Each four-bit group encodes one decimal digit. Spaces only help us see the grouping.

“Read BCD 0010 0111 as one eight-bit binary value.”

False. Decode 0010 → 2 and 0111 → 7. The BCD value is 27.

“Every four-bit pattern is a valid BCD digit.”

False. Only 0000 through 1001 represent decimal digits 0–9. For example, 1010 is not a valid BCD digit.

Show answer guide
  • Write the 8-bit place values from 128 down to 1.
  • Start with the largest value and test whether it fits.
  • Write 1 if it fits and subtract it from the remaining value.
  • Write 0 if it does not fit, then move to the next column.
5 marks Compare

Question 2

Compare pure binary and BCD for a device that needs to show decimal digits on a display.

Show answer guide
  • Pure binary stores the whole value as one binary number.
  • BCD stores each denary digit as a separate 4-bit group.
  • BCD can make decimal display simpler because each digit stays separate.
  • Pure binary is usually more storage efficient.
  • For example, 255 uses 8 bits in pure binary but 12 bits in BCD: three decimal digits × four bits.
3 marks Explain

Question 3

Explain why electronic computers use binary, and why the bits need an agreed interpretation.

Show answer guide
  • Electronic systems reliably distinguish two states, represented by 0 and 1.
  • Combining bits provides many patterns for representing data.
  • An agreed rule determines what a pattern means: for example, a number or a character.
