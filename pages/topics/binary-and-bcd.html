Overview

Binary starts with the simplest possible choice

A bit is a single binary digit. It can be 0 or 1. That sounds tiny, but it matters because computer hardware is very good at storing and detecting two stable states: off or on, low voltage or high voltage, false or true.

One bit

One yes/no choice: 0 or 1.

Many bits

Bit patterns can represent numbers, text, images, and sound.

Computer data

Programs use agreed rules so the same bits can be interpreted correctly.

Learning goals

  • Explain what binary numbers are and why computers use them.
  • Describe what a number base means.
  • Use an 8-bit place value table accurately.
  • Convert values between denary and binary.
  • Explain how BCD is different from pure binary.

Quick memory hooks

  • Binary: base 2, using 0 and 1.
  • Denary: base 10, using digits 0 to 9.
  • Hexadecimal: base 16, useful shorthand for binary.
  • BCD: each denary digit gets its own 4-bit binary code.

Bases

A number base tells you how the columns grow

A base is the counting system being used. It tells you how many symbols are available before you carry into the next column, and it controls the place values in the table.

Base 10

Denary

Uses ten symbols: 0 to 9. Place values grow by multiplying by 10.

1000 100 10 1
Base 2

Binary

Uses two symbols: 0 and 1. Place values grow by multiplying by 2.

8 4 2 1
Base 16

Hexadecimal

Uses 0 to 9 and A to F. It is often used as a compact way to write long binary patterns.

0-9 A B F

Why mention hexadecimal here?

Hexadecimal appears often in computing because each hex digit can represent a group of four binary bits. This lesson only needs the idea that hex is another base. Detailed hexadecimal conversion is covered in the next lesson.

Place Value

Binary place value doubles as you move left

In an 8-bit binary number, the columns are 128, 64, 32, 16, 8, 4, 2, 1. A 1 means include that value. A 0 means leave it out.

Example: binary 10101101 includes 128, 32, 8, 4, and 1.
Value 128 64 32 16 8 4 2 1
Power 27 26 25 24 23 22 21 20
Bit 1 0 1 0 1 1 0 1

Denary total 173
8-bit binary 10101101

Conversion

Conversion is controlled by the place value table

Binary to denary and denary to binary use the same table, just in opposite directions. One asks, "Which columns are switched on?" The other asks, "Which columns do I need to switch on?"

Binary to denary

Add the active columns

  1. Write the place values above the bits.
  2. Find every column with a 1.
  3. Add those values together.
  4. The total is the denary answer.
Denary to binary

Subtract powers of 2

  1. Start with the largest place value in the table.
  2. If it fits into the remaining number, write 1.
  3. Subtract it, then move to the next column.
  4. If it does not fit, write 0 and move on.

BCD

Binary coded decimal stores each decimal digit separately

Pure binary converts the whole number into one binary value. BCD takes each denary digit and stores that digit as a separate 4-bit binary pattern.

Denary digit 2 0010
Denary digit 7 0111
BCD result 27 0010 0111

Pure binary for 27

The whole number is converted into one value: 00011011.

BCD for 27

The 2 and the 7 are encoded separately: 0010 0111.

The trade-off

BCD can make decimal display and entry simpler, but it often uses more bits than pure binary.

Exam Traps

Common mistakes with binary and BCD

Reading BCD as one pure binary number

In BCD, each decimal digit is handled separately. The bit string must be split into 4-bit groups before it is read.

Fix: Group BCD from left to right in nibbles.

Writing place values in the wrong order

Binary columns must follow powers of 2. Reversing the table changes the value.

Fix: Write 128 64 32 16 8 4 2 1 above 8-bit questions.

Dropping required leading zeros

Leading zeros do not change the number, but the question may ask for an 8-bit answer.

Fix: Match the requested bit width.

4 marks Explain

Question 1

Describe the strategy used to convert a denary number into binary using an 8-bit place value table.

Show answer guide
  • Write the 8-bit place values from 128 down to 1.
  • Start with the largest value and test whether it fits.
  • Write 1 if it fits and subtract it from the remaining value.
  • Write 0 if it does not fit, then move to the next column.
5 marks Compare

Question 2

Compare pure binary and BCD for a device that needs to show decimal digits on a display.

Show answer guide
  • Pure binary stores the whole value as one binary number.
  • BCD stores each denary digit as a separate 4-bit group.
  • BCD can make decimal display simpler because each digit stays separate.
  • Pure binary is usually more storage efficient.
