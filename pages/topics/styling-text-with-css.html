CSS Rule Anatomy

A rule contains a selector and declarations

.featured-text {
color: purple;
font-weight: bold;
}
Selector
.featured-text identifies the elements.
Property
color names what should change.
Value
purple says how it should change.
Declaration
color: purple; is one complete instruction.
Colon :Separates a property from its value.
Semicolon ;Ends a declaration before the next one begins.

Colour and Size

Start with two visible text changes

color: purple;

Text colour

The property uses the American spelling color. Begin with simple named colours such as purple, red, green, or blue. A future colour lesson will explore other ways to describe colours.

font-size: 24px;

Text size

24 is the value and px means pixels. The next lesson focuses on choosing between CSS units; today, use px values for simple experiments.

Keep HTML meaningful. Use heading elements because content is a heading, not merely to obtain larger text. CSS controls appearance.

Weight, style, and decoration affect the shape of text

font-weight: bold;Changes thickness

normal can return weight or style to its normal appearance. none removes a text decoration.

Alignment and Spacing

Control the line as well as each character

text-align: center;

Horizontal alignment

Use left, center, or right. This aligns inline content inside the selected element; it does not move the element itself.

line-height: 1.5;

Space between lines

A unitless value of 1.5 gives each line one-and-a-half times the current text size.

line-height: 1;
Closely packed lines can make longer text harder to scan. Compare the vertical gap between these lines.

line-height: 1.5;
More breathing room can make a paragraph easier to follow without changing the words.

Choosing a Selector

Do you mean every paragraph or a particular paragraph?

REPETITIVE
<p class="normal-text">...</p>
<p class="normal-text">...</p>
<p class="normal-text">...</p>

Adding the same class everywhere is unnecessary when every paragraph genuinely needs the same starting style.

SIMPLER
p {
  font-size: 18px;
  line-height: 1.5;
}

The element selector expresses “every paragraph” directly.

Choose by meaning: use p for a broad paragraph rule and a class such as .featured-text for a particular reusable role.

Rules Working Together

A featured paragraph can match both rules

p {
  line-height: 1.5;
}Every paragraph
+
.featured-text {
  color: purple;
}The featured element
→
Featured paragraphcomfortable line spacingpurple text

Text version: a featured paragraph is a paragraph and has the featured-text class, so it matches both selectors. Each rule contributes a different property.

Readable CSS

Use clear formatting and learn one more property name

font-family: Arial;

This property chooses the typeface. A later lesson will properly cover fonts installed on a system, fallback and generic families, and loading external web fonts.

One declaration per line

.featured-text {
  color: purple;
  font-weight: bold;
  line-height: 1.5;
}

Indent declarations and keep the closing brace easy to find.

Common Mistakes

Keep these distinctions clear

Property ≠ value

font-weight is the property; bold is its value.

Alignment ≠ movement

text-align aligns content inside an element. It does not reposition the element.

Size ≠ meaning

Making a paragraph large does not turn it into a heading.

Spelling matters

CSS uses color, and an unrecognised property is ignored.

Punctuation matters

The colon separates property and value; the semicolon ends the declaration.

Classes are purposeful

Use a class for a particular role, not automatically on every element.

CSS stays in the stylesheet

Do not place a declaration such as color: purple; inside normal HTML text or attributes.

Glossary

Quick glossary

Property
The part of a declaration that names what should change.
Value
The setting assigned to a property.
Declaration
A property and value instruction, normally ending with a semicolon.
px
A CSS unit meaning pixels.
Line height
The vertical space used by each line of text.

Remember

The pattern

  • Selector opens the rule
  • Property comes before the colon
  • Value comes after the colon
  • Semicolon ends the declaration
  • Closing brace ends the rule
