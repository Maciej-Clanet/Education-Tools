Glossary

Quick glossary

Integer
A whole number, such as −12, 0 or 12.
Magnitude
The size of a value without its sign.
Two's complement
A rule for signed whole numbers. The leftmost place value is negative.
Binary point
The point between whole-number places and fraction places.
Mantissa (significand)
The main digits of a floating point value.
Exponent
The power of two that multiplies the mantissa.
Normalisation
Writing the mantissa in the standard form for a format.
Range
The values a format can represent.
Precision
The detail a format can keep.
Overflow
A value is outside the available range at the large end.
Underflow
A nonzero value is too close to zero for the available format.

Remember

Range versus precision

  • Unsigned binary cannot represent negative values.
  • Two's complement is for signed whole numbers.
  • Our floating point format uses a sign, mantissa and exponent.
  • More range can mean less precision in a fixed size.
