Overview

Binary patterns need an agreed interpretation

A pattern such as 11111011 is just eight bits. It only becomes a value when the system knows the representation being used. The same pattern can mean an unsigned integer, a negative two's complement value, part of a floating point number, or something else entirely.

Unsigned binary

Uses every bit for size, so values run from zero upwards.

Two's complement

Uses the bit pattern range to cover positive and negative whole numbers.

Floating point

Splits storage into sign, exponent, and significand so the point can move.

Learning goals

  • Explain why unsigned binary cannot represent negatives.
  • Convert small values using 8-bit two's complement.
  • Describe sign, exponent, and significand in floating point.

The big idea

The CPU does not store a minus symbol or a decimal point as a handwritten mark. It stores bits, then interprets those bits according to a chosen format.

Bit Width

The number of bits controls the range

A fixed number of bits gives a fixed number of patterns. With 8 bits there are 256 patterns. Unsigned binary spends all 256 on values from 0 to 255. Two's complement splits them across negative and non-negative values, from -128 to 127.

8-bit unsigned

0 255

All patterns represent zero or a positive whole number.

8-bit two's complement

-128 0 127

The same 256 patterns are interpreted around zero.

Bit width Number of patterns Unsigned range Two's complement range
4 bits 16 0 to 15 -8 to 7
8 bits 256 0 to 255 -128 to 127

Negative Numbers

Negative binary is a representation choice

A simple approach is sign and magnitude: use the leftmost bit for the sign and the remaining bits for the size. That is easy to understand, but it creates awkward arithmetic cases. Two's complement is the common method because addition and subtraction can use the same binary hardware.

Sign and magnitude

1 0 0 0 0 1 0 1

The sign bit says negative, and the remaining bits show the magnitude. The idea is readable, but arithmetic is less neat.

Two's complement

11111111 = -1 00000000 = 0 00000001 = 1

The bit patterns wrap around zero. This means adding 00000001 to 11111111 produces 00000000, just like -1 + 1 = 0.

Two's Complement

To make a negative value, invert the positive bits and add 1

For an 8-bit negative value, start with the positive magnitude, flip every bit, then add 1. Keep the full 8-bit pattern, including leading bits.

Floating Point

Floating point stores the point position separately

Floating point is useful when a value might be fractional, very large, or very small. It works like scientific notation: store the sign, store the main digits, and store a power that scales the value.

Sign 0 or 1

Whether the value is positive or negative.

Significand 1.xxxxx

The main precision bits, sometimes called the mantissa.

Exponent 2^n

How far the binary point has moved.

Worked idea

The binary value 1101.01 can be written as 1.10101 x 2^3. The significand is 1.10101 and the exponent is 3 because the point moved three places left.

Normalisation

Normalising keeps one non-zero digit before the point

A normalised binary floating point value is usually written with one leading 1 before the binary point. Moving the point left gives a positive exponent. Moving it right gives a negative exponent.

Precision

Floating point trades exactness for range

A floating point format has a limited number of bits. Giving more bits to the exponent increases range. Giving more bits to the significand increases precision. You cannot maximise both in the same fixed-size format.

This setup balances range and precision.

Rounding The closest representable value is stored.
Overflow The value is too large for the exponent range.
Underflow The value is too close to zero to represent accurately.
Precision loss Small detail is lost because there are not enough bits.

Exam Traps

Common mistakes with negative and floating point values

Dropping leading bits

In two's complement, the full bit width matters. Removing a leading 1 can change the value completely.

Fix: Keep all bits stated by the question, especially in 8-bit examples.

Treating every first bit as just a sign

In two's complement the leftmost bit helps indicate the negative range, but the whole pattern determines the value.

Fix: Decode the whole bit pattern, not only the first bit.

Assuming floating point is exact

Some values cannot be represented exactly with the available significand bits.

Fix: Mention rounding, precision loss, or approximation when asked about limitations.

Glossary

Quick glossary

Two's complement
A common method for representing signed integers.
Significand
The main precision digits in a floating point value.
Exponent
The part that scales a floating point value.
Overflow
A value is too large for the available range.
Underflow
A value is too close to zero to represent accurately.

Remember

Range versus precision

  • Unsigned binary cannot represent negative values.
  • Two's complement is for signed whole numbers.
  • Floating point uses sign, significand, and exponent.
  • More range can mean less precision in a fixed size.
