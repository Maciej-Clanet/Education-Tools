Overview

What this web development hub will cover

This page will collect web development topics that can be used for lessons, independent practice, and quick classroom reference. The first HTML basics lessons introduce what HTML is and how document structure works, then move into common content tags, nested relationships, file paths, and forms. CSS basics begins by connecting external stylesheets, then introduces selectors.

Teaching flow

Start with page structure, connect and organise styling, learn how selectors target elements, then build towards browser interactivity.

Resource shape

Each topic can grow into a lesson page with examples, practice tasks, common mistakes, and short checks for understanding.
